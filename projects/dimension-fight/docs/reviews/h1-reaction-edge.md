# H1 코너 피격·KO 표시 검수

2026-10-03 · 기준 `fe43d4c` · **구현·자동/화면 검수 완료**. 사용자 **“현재 대전 체감·화면 보완 (권장)”** 선택으로 [표시 보완 명세](../specs/h1-reaction-edge.md)의 일반 피격2개·KO3개를 수정했다. 전투/AI/음원/원화 변경 없이 표시 위치만 보완했다.

## 원인과 측정

`combatVisual`은 성공 메치기 외에는 논리x를 그대로 반환했다. 이동 한계80~1200은 그림의 전체 폭을 고려한 화면 한계가 아니므로 넓은 피격/쓰러짐이 잘렸다. 이전 [경기 검수](h1-match-flow.md)의 오른쪽 KO 잘림이 남아 있는 것을 공통 전투와 원화로 재현했다.

오른쪽 x1200·왼쪽을 보는 대상과 왼쪽 x80·오른쪽을 보는 대상은 대칭이다. 원화512×512·배율0.625·기준x256의 픽셀 셀을 화면으로 변환했다. 정렬 manifest의 alpha≥8 본체 범위와 실제 PNG의 모든 alpha>0 범위를 구분한다. 아래 수치는 전투의 사거리나 밀려남 값이 아니다.

| 포즈 | alpha≥8 기준 바깥 폭 | 모든 alpha>0 기준 바깥 폭 |
|---|---:|---:|
| 선 피격 | 12.5px | 46.875px |
| 앉은 피격 | 0px | 9.375px |
| KO0 | 8.125px | 33.75px |
| KO1 | 27.5px | 50.625px |
| KO2 | 49.375px | 49.375px |

실제 표시 보정은 미약한 외곽 픽셀도 포함하는 alpha>0 범위를 사용한다. 이미 온전히 들어오는 위치에는 보정을 적용하지 않고, 밖으로 나가는 만큼만 이미지와 이름표의x를 바꾼다. 피격 사각형·논리 루트·바닥y·원화 크기·포즈/시간표는 유지한다. KO 연출 나이를 그림 선택과 표시 함수에 같이 전달해 결과 대기의 마지막 자세도 맞춘다.

상수 표의 실제 픽셀 셀 경계는 선 피격[53,416), 앉은 피격[113,379), KO0[74,422), KO1[47,466), KO2[49,466)이다. 양쪽 코너에서 안쪽/바깥쪽 방향을 모두 조합한 표시 검사까지 포함하면 최대 보정은 KO1/2의51.25px다. 위 표는 일반적인 안쪽 보기 사례다.

## 검증

- 새 반응 검사7개를 구현 전에 실행해5개 실패/2개 통과를 확인했다. 실제 PNG alpha>0를 독립 디코딩하는 경계 검사로 잘림을 재현한 뒤 구현했다.
- 구현 후 **전체288/288**(기존281+반응7), TypeScript 포함 빌드 통과. 기존 Phaser 청크 크기 경고만 남는다. 원화/음원은 변경하지 않아 생성/인코딩 검사는 다시 하지 않았다.
- 좌우 경계와 반전, 실제 공통 약손의 선/앉은 피격·KO, KO나이0/5/6/11/12/18 및 결과 대기, 중앙 불변, 피격 회복, 공중 KO의 기존 지면 표시, 논리 루트/피격 사각형/후속 공통 경기 불변을 확인했다. 기존 메치기와 종료 스냅샷에도 새 보정이 들어가지 않음을 검사했다.
- 독립 코드 검토에서 추가 결함0건. 픽셀 셀의 우측 끝을 제외 경계로 취급하고, 반전 후 양끝의 min/max로 필요한 최소x만 이동하는지 대조했다. 양쪽 화면과 기존 AI-G 시각 검수는 동일 KO 나이를 전달한다.

## 브라우저 비교

[비교 화면](evidence/h1-reaction-edge-review.html)은 개발 서버4175의 같은 경로에서 연다. 처음 위치/HP만 지정하고 공통 약손/강손으로 피해를 만든 검수 배치다. 기존 표시 체크는 같은 경기 상태에서 이미지/이름표x만 논리 루트로 되돌린다. 오디오나 실제 키 입력을 재생하지 않는다.

## 범위와 남은 항목

최신 빌드4174의 표적/AI 경기 둘 다 이미지 로딩 완료 후 시작·Esc 정지가 동작했다. 두 빌드 탭과 비교 탭의 warn/error는0이었다. 빌드 화면에서 직접 코너 KO를 새로 만든 것은 아니며, 코너의 전후 동작은 위 공통 모듈 비교 화면과 자동 검사로 확인했다.

이번 대상은 일반 피격·KO다. 기존 성공 메치기의 공중/다운 보정과 연출은 유지한다. 일부 대기·붙잡음/복귀·메치기 공격자 포즈의 코너 잘림도 읽기/계산 검토에서 확인했으나, 접촉/발 정렬 검토가 필요한 별도 범위로 남긴다. 사람의 연출 자연스러움·대전 난이도·청취 체감을 이번 수학적 경계 확인으로 대신하지 않는다.
