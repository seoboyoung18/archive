# H1 코너 피격·KO 표시 보완

최신 화면 규칙(2026-10-03): 사용자가 승인한 [거리 대응 카메라 A](h1-camera-framing.md)가 아래 개별/쌍 표시x 보정 규칙을 대체한다. 원래 메치기 곡선·높이·회전과 전투 시간표는 유지하고, 모든 그림·판정·이름표·배경에 공통 변환을 적용한다. 아래 수치와 검수는 해당 단계의 이력이다.

이 문서는 첫 반응 보완의 범위와 완료 이력이다. 별도 후속으로 남긴 대기·붙잡음·메치기 표시는 [후속 명세](h1-grab-edge.md)에서 보완하며, 일반 반응의 실제 알파 경계와 KO 나이 일치 규칙은 유지한다.

2026-10-03 · 사용자 “다음 진행하자” 및 **“현재 대전 체감·화면 보완 (권장)”** 선택에 따른 결함 보완. 신규 전투 수치/기술 선택 없이, 기존 검수에 남겨 둔 일반 피격·쓰러짐 그림의 경계 잘림을 수정한다.

## 문제와 범위

논리 루트는80~1200이고 화면은1280×720이다. 현재 일반 피격/KO는 `combatVisual`에서 논리x 그대로 반환한다.512px 원화에0.625 배율을 적용하면 넓은 몸이 코너 밖으로 나간다. 기존 정렬 manifest(alpha≥8)의 오른쪽·왼쪽 대칭 사례에서 선 피격은12.5px, KO 마지막 그림은49.375px가 잘린다. 실제 PNG의 모든 alpha>0 범위를 추가 측정해 최종 표시/검증 기준으로 사용한다.

이번 작업은 **일반 hit의 선/앉은 피격2개와 일반 KO3개** 표시로 한정한다. 공통 전투 상태·위치·몸통 판정·피해/밀려남·경직·KO18F·기본100포즈·음원·AI 정책은 유지한다. 별도의 새 기술·카메라 이동/확대·원화 재제작은 하지 않는다.

메치기에서 이미 적용한 공중/다운의 표시 보정은 그대로 유지한다. 읽기/계산 검토에서 추가로 확인한 일부 붙잡음/복귀·공격자 및 대기 자세의 코너 잘림은 별도 후속이다. 움직임/접촉의 발 정렬까지 함께 검토할 대상이며, 이 일반 피격/KO 수정으로 모든 동작이 화면 안에 든다고 주장하지 않는다.

## 기대 동작

1. 중앙 또는 원화가 온전히 들어오는 위치에서는 기존 표시가 그대로다.
2. 선/앉은 피격과 일반 KO에서 현재 **표시하는 포즈**의 실제 수평 알파 범위가 화면 밖으로 나갈 때만, 넘친 길이만큼 표시x를 이동한다. 좌우 반전도 동일하게 적용한다. 투명 여백을 몸으로 취급하지 않는다.
3. 경계 안으로 옮기는 것은 이미지와 이름표뿐이다. 논리 발 기준점·피격 사각형·충돌/이동은 이전 상태를 사용한다. 일반 피격은 기존 y, 일반 KO는 기존 지면y를 유지한다.
4. KO0~5/6~11/12F 이후의 그림 선택과 위치 보정에 같은 KO 연출 나이를 전달한다.18F 이후 결과 대기에도 마지막 그림의 보정이 유지된다.
5. 피격 회복 후 다른 행동은 기존 논리 루트 표시로 돌아온다. 새 보간 시간이나 회복 잠금을 추가하지 않는다. 실제 원화의 포즈 전환만큼만 표시 위치가 달라질 수 있다.
6. 성공 메치기와 종료 스냅샷은 기존 `combatVisual` 경로가 우선하며 새 일반 KO 보정을 중복 적용하지 않는다.

## 구현과 검증

H1 표시 함수에 현재 원화의 작은 반응 포즈 수평 범위 표를 두고, KO 포즈 결정은 기존 `combatPose`를 재사용한다. 런타임에서 PNG를 디코딩하지 않는다. 범위 표는 테스트에서 실제 PNG 알파와 대조해 원화 교체 시 낡은 수치가 남지 않도록 한다. 양쪽 실행 화면은 이미 사용하는 KO 나이를 표시 함수에도 전달한다.

검증은 변경 전 실패하는 코너 경계 검사, 원화의 모든 alpha>0 포함, 양쪽 경계/좌우·각 KO 포즈 전환·중앙 불변·논리 전투 상태 불변·피격 회복·메치기 회귀로 한다. 타입/빌드와 관련 전체 회귀 검사를 수행한다. 별도 입력 재현 화면에서 공통 전투로 만든 피격/KO를 변경 전 표시와 비교하며 초기 위치/체력을 지정한 검수 배치임을 명시한다. 실제 키로 접근해 KO를 만드는 검수와는 구분한다.

구현 후288개 검사·타입/빌드와 비교 화면의 좌우/중앙·피격/KO 확인을 완료했다. 완료 결과·측정값·실제 화면 확인·남은 체감은 [검수 기록](../reviews/h1-reaction-edge.md)과 개발일지에 남긴다. 사람의 실제 대전/입력·연출 자연스러움 전체가 검증됐다는 의미는 아니다.
