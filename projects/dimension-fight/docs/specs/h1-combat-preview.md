# H1 전투 포즈·화면 연결 단계

2026-10-01. 승인된 전투/애니메이션 v0.3과 [전투 로직](h1-combat-core.md)을 연결한다.

## 범위

- 미제작 공격6종(선 강손/약발/강발, 앉은 약손/강손/강발)의 준비·유효·회복18장, 선/앉은 방어·피격4장, 쓰러짐3장, 총25장 시안을 제작·정렬·검수한다. 원본·v1/v2/movement-v1은 보존한다.
- 기존 승인대로 ImageGen 편집과 비율 유지 축소/투명 배치만 사용한다. 생성 원화와 정확한 프롬프트, 변환/해시를 `combat-v1`에 저장한다. 얼굴·의상·팔다리를 코드로 다시 그리거나 이미지 크기로 판정을 바꾸지 않는다.
- 출력512×512·루트(256,448)·표시0.625 유지. 같은 원화 캔버스 높이에 대한 공통 축소율을 적용한다. 지상 발/쓰러진 신체 하단을448에 정렬하며 포즈별 바운딩 박스 높이로 재확대하지 않는다.
- `combat.html`에 PLAYER 대 입력 없는 CPU 표적 검수 화면을 추가한다. WASD+U/I/J/K, 체력·공격 구간/피격 표시·정지/재개·초기화로 판정 연결을 확인한다. AI·라운드 시계·승수·캐릭터 선택은 후속 단계다.
- 검수용 상대 입력은 없음/선 뒤/앉은 뒤를 선택하여 방어 연결도 확인한다. 이는 출시 기능·난이도·AI가 아니라 명시적 검수 도구다. 선택 변경 시 정지하며 재개 전 입력을 초기화한다.
- KO에서는 전투 상태를 고정하고 쓰러짐3장을 각6F만 진행한다. 상대 포즈는 종료 순간 그대로 둔다. 일시정지 중 KO 그림도 멈춘다. 검수 초기화는 전체 상태/입력/연출을 복원한다.
- 필수 이미지 누락 시 시작 차단·안내·재시도. 미제작 포즈를 대기 그림으로 대체하지 않는다. 공격 그림은 `attackPhase`와 같은 나이로 선택한다.

## 설계·계획

기존 이동/공격 시안 페이지를 유지한다. 새 화면은 전투 함수·입력 버퍼·고정 시간 모듈을 사용한다. 41포즈 경로와 상태별 선택은 별도 표현 모듈에 둔다. 이미지 파일이 판정 데이터를 소유하지 않는다. 검수용 방어 입력도 일반 방향 입력으로 전달한다.

1. 25장 원화 생성, 일관성/잘림 검토 후 공통 정렬. 부적합한 후보는 재생성하고 상태를 기록한다.
2. 이미지 검사와41포즈 선택/공격 구간/KO 연출 경계 테스트.
3. 새 전투 검수 화면에 연결하고 빌드·기존53테스트 회귀.
4. 브라우저 로딩·키보드 공격/피해·정지/초기화/표적 선택을 확인한다. 자동 검사와 실제 육안 확인을 구분하며, 최종 타격감·모든 포즈의 플레이 적합성은 별도로 남긴다.
5. 명세/계획/검수 기록/개발일지 동기화 및 커밋. 트러블슈팅 발생 시 지정 Notion에 기록한다.
