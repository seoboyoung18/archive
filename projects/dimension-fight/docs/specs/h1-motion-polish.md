# H1 모션 보완 1차 · 2026-10-01

사용자가 전체 모션의 끊김을 지적하고 “걷기·기본 공격부터 보완”을 선택했다. 이번에는 걷기와 선 약손을 먼저 보완해 비교한다. 다른7공격·점프·KO의 전체 보완은 후속이며 완료했다고 보고하지 않는다.

## 구현 기준

- 원본과 이전41포즈를 보존하고 `motion-v1`에7개 중간 포즈를 추가한다. 규격512×512, 루트(256,448), 동일384/1120 배율을 유지한다.
- 걷기: 기존0→1→2→3→0 사이에 중간 그림4개를 추가한다. 기존 주기24F는 유지하고8그림을 각3F 표시한다. 이동 속도240과 판정은 변경하지 않는다.
- 선 약손: 준비6F=기존 준비3F+팔 뻗기 중간3F, 유효3F=기존 타격, 회복15F=팔 거두기 중간5F+기존 회복5F+대기 복귀 중간5F. 총24F·피해8·유효 구간6~8F 유지.
- 추가 포즈의 몸 크기·얼굴·의상·발 위치를 기준 이미지와 비교한다. 펀치는 팔만 바꾸며 발은 고정한다. 걷기는 두 기준 포즈 사이 자세를 생성한다. 이미지 얼굴·팔다리를 코드로 합성/재도색하지 않는다.
- 보완 포즈는 전투 검수 화면에 먼저 연결한다. 기존 이동/공격 시안 페이지는 이전 시안 비교용으로 유지한다. 포즈 선택은 공통 전투의 나이에만 의존한다.
- 이미지 겹치기/불투명도 전환으로 두 팔·두 발이 겹쳐 보이는 방법은 사용하지 않는다. 일시정지·KO 이후 포즈 고정은 기존대로 유지한다.

## 검증

7개 원화/정렬 출력·정확한 프롬프트·해시 저장, 기준 이미지/이전 에셋 불변. 포즈48경로, 걷기8구간/24F 반복, 선 약손6그림과 기존 판정 구간 유지, 회귀 테스트·빌드·브라우저 확인. 포즈 증가가 전체 모션 품질 승인과 같지 않으므로 실제 관측과 남은 흔들림을 구분해 기록한다.
