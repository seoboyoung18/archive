# H1 입력·이동 단계 명세

> 2026-10-03 최신 변경: [회전 점프·중간 그림](h1-smooth-flip.md)을 우선 적용한다. 아래의 공중 최소 간격/통과 금지와 3장 점프·4장 보행은 초기 구현 이력이다. 현재 공중 통과, 한 바퀴 회전, 착지 방향 전환, 24장 보행·4장 대기와 표시 보간을 사용하며 이동/점프 수치는 유지한다.

2026-09-30. 승인된 전투 v0.3 중 입력·이동·접촉·일시정지 부분을 구현한다. 사용자 요청의 다음 단계이며 수치와 게임 범위를 새로 결정하지 않는다.

## 범위
- 대기 추가1장, 걷기4장, 점프 상승/정점/하강3장을 ImageGen으로 제작. 기준 이미지·v1/v2 보존, 새 원화/프롬프트/정렬값을 movement-v1에 보존한다.
- 512×512, 발 기준점(256,448), 표시0.625와 기존 대기 기준 공통 축소 배율을 유지한다. 점프의 접은 발은 지면에 다시 맞추지 않고 원화의 가상 지면(기존 대기의1194)을 기준으로 배치한다. 몸 전체를 캔버스 위로 이동시키는 연출은 하지 않는다.
- 기존 공격 시안 페이지는 보존한다. 별도 `movement.html`에 H1 이동 검증 화면을 추가한다. PLAYER와 입력 없는 CPU 표적으로 두 선수의 접촉을 검증한다. CPU의 자발적 이동/AI와 공격·방어·피해·경기는 다음 단계다.
- WASD, 상대 방향 바라보기, 전진/후진, S 앉기, W 점프, 지상/공중 접촉·경계, 시작/정지/재개·검수 초기화를 제공한다. 초기화는 이 검수 화면의 제어이며 경기 결과의 R 재시작 규칙을 바꾸지 않는다.

## 동작 기준
- 논리1280×720, 지면600, x80~1200, 시작400/880, 최소 간격72. 두 선수 이동을 동시에 계산하고 겹침을 반씩 분리하며 막힌 분리량은 다른 선수에 적용한다.
- 초당60회, 이동240/초, 점프 초기속도-800, 중력2000. 위치는 일정 가속도로 적분한다. 착지 시 지면·속도0 보정, 현재 S 자세 적용. 공중에도 좌우 이동 가능, 재점프 없음.
- A+D와 W+S는 각 축 중립. S가 유효할 때 지상 이동0. W는 새 누름만 점프, OS 반복 무시, 공중 입력은 착지 후 예약하지 않는다.
- 지상에서는 상대를 향하고 공중에서는 이륙 방향을 유지한다. 뒤 이동도 같은 걷기4포즈 주기다.
- 대기2포즈 각15F, 걷기4포즈 각6F. 점프 포즈는 vy<-100/ -100~100/ >100으로 선택한다. 모든 포즈 시간은 처리한 논리 프레임을 따른다.
- 렌더당 최대5F, 과도한 지연은 버린다. 일시정지 중 논리·그림·누적시간 정지. Esc/포커스 상실/탭 숨김에 정지하고 명시적 버튼·Enter·Esc로만 재개한다.
- 시작/재개/초기화에서 키 상태를 비우고 유지하던 키는 해제 후 재입력해야 한다. 사용 키의 브라우저 기본 동작은 활성 게임 영역 안에서만 차단한다. UI 버튼 입력을 이동 입력으로 전달하지 않는다.
- 필수 이미지 로딩 실패는 시작을 막고 안내/재시도 버튼을 표시한다. 기준 이미지로 대체하지 않는다.

## 구조
- `src/combat/movement.ts`: Phaser/DOM 없는 두 선수 이동·접촉·자세·방향 처리. 캐릭터 이동 수치를 인자로 받는다.
- `src/input/movement-input.ts`: 물리 키 유지/누름/해제와 초기화. DOM 이벤트 연결은 화면 계층에서 수행한다.
- `src/combat/fixed-step.ts`: 60Hz 누적과 최대5회 처리. 정지/재개 시 누적 제거.
- `src/movement.ts`: Phaser 로딩·표시·입력 연결·검수 UI. 새 전투 행동·체력/경기 상태를 미리 만들지 않는다.

## 검증 기준
1. 60회 이동=240, 방향 중립/앉기, 상대 위치별 방향과 공중 방향 유지.
2. 점프 정점 약160높이·약0.8초 후 착지, 이중 점프/유지키 재점프 없음, 착지 S 반영.
3. 양쪽 경계·동시 접근·코너·공중에서 최소 간격72 유지하고 통과 없음.
4. 고정 시간 입력 기록을 다른 렌더 간격으로 공급해 동일 결과. 과부하 최대5회·일시정지 누적 초기화.
5. 물리 키 반복/동시 입력·포커스 상실/재개·검수 초기화에서 입력 잔류 없음.
6. 에셋 자동 검사, 타이밍/이동/입력 단위 테스트, 타입 검사·다중 페이지 빌드, 실제 브라우저 키보드·정지/초기화·이미지 표시 확인.
7. 검증한 항목과 미확인 브라우저/시각 품질을 구분하여 개발일지·검수 기록·Notion에 기록한다. 이 단계 결과를 전투 V01~V28 전체 통과로 보고하지 않는다.
