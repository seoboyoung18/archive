# H1 회전 점프·중간 그림 보완

2026-10-03 사용자 요청: “점프 하면 한바퀴 돌면서 상대 넘어가게 하고 전체적으로 프레임을 더 부드럽게 하자 이미지 더 뽑아서 진짜 부드럽게”. 입력 선택은 **W는 제자리, W+A/D는 방향 점프 · 공중에서 상대 통과**다. 기존 점프 높이·체공 시간 유지 방향을 함께 확인했다.

## 확정 범위

- W 새 누름으로 기존 점프를 시작한다. W만 누르면 제자리, A/D로 방향 이동하며 기존 공중 방향 조절은 유지한다. 상대 방향으로 자동 이동하지 않는다.
- 이동240/초·초기 수직속도-800·중력2000·높이 약160·체공48F를 유지한다. 지상끼리 간격72, x80~1200 경계도 유지한다. 어느 한쪽이라도 공중이면 수평 몸 밀어내기를 하지 않아 상대를 넘어갈 수 있다. 둘 다 지상으로 돌아오면 현재 위치 순서로 간격을 해소한다.
- 통과는 양 선수에게 대칭이다. 상대가 점퍼 아래를 지나거나 양쪽 점퍼가 교차할 수도 있다. 착지x가 정확히 같으면 직전 좌우 순서를 보존하며, 착지 후 간격72 미만은 기존 분리 규칙을 따른다. 이륙 거리가 멀어 기존 수평 이동192 안에서 도달하지 못하면 자동으로 상대 뒤에 배치하지 않는다.
- 자유 점프는 이륙 시 바라본 방향으로 한 바퀴 전방 회전하고, 지상 착지 즉시 상대를 향한다. 공중 공격·방어·추가 무적·점프 피해는 넣지 않는다. 피격/KO로 자유 점프가 끝나면 기존 반응 연출을 우선한다.
- 기존 전투 시간·공격 준비/유효/회복·콤보 창·잡기 시간표·피해·AI 선택·음원은 유지한다. 그림을 늘려도 판정 틱을 늘리거나 같은 공격을 다시 시작하지 않는다.
- 새 원화·프롬프트·정렬 결과는 버전별 새 경로에 보존한다. 동일 인물/의상·512 캔버스·공통 체형 크기/발 기준점을 유지한다. 신규 그림 수/배분은 제작 결과로 기록하며 중복 그림을 새 고유 포즈로 세지 않는다.
- 위치와 회전의 렌더 사이 표시를 보완하되 논리60Hz·입력 처리·공격 포즈의 실제 age 기준을 유지한다. 정지·초기화·종료와 피격/잡기처럼 동작이 끊기는 경계는 새 상태를 즉시 표시한다. 피해 판정을 과거 위치나 렌더 위치로 계산하지 않는다.

## 제작·구현 순서

1. 현재 점프/충돌과 그림 유지 길이를 분석한다.
2. 회전용 접기·펼치기와 대기·보행·기본 공격·반응/잡기의 중간 그림을 제작·정렬한다. 새 원화의 얼굴·손발·체형·접촉·512 경계를 확인하고 부적합 후보는 연결하지 않는다.
3. 새 원화의 범위를 공통 카메라 여유192와 대조한다. 보이는 크기를 임의로 추가 축소해 문제를 숨기지 않는다.
4. 이동/착지/교차 타격과 화면 보완을 연결한다. 별도 비교 화면에서 기존/신규 재생을 확인한다.
5. 논리 회귀·원화·타입/빌드·실제 브라우저 확인 후 문서/일지/Notion을 동기화하고 단위 커밋·push한다.

## 검증 기준

제자리/양방향/양 선수 점프·양 끝·교차/착지 동률·재점프 차단·공중 피격/KO·정지/재개/초기화, 교차 틱의 일괄 타격·방향 전환을 확인한다. 공격8종/콤보/잡기/소리의 기존 실제 사건은 유지한다. 포즈 원화의 실제 알파 범위·체형·지지발/접촉과 회전 궤적을 확인하고, 계산 검사·그림 검수·사람의 실제 체감은 구분한다.

## 그림 일정과 표시 설계

- 새 고유 원화45장: 회전7, 보행 사이12, 대기 사이2, 공격 준비/회복 각8, 피격/KO/잡기8. 기존100개 키를 보존해 등록145개다. 폐기 후보는 `rejected` 이름으로 원본만 보존하며 등록하거나 세지 않는다.
- 보행은 기존12장의 각 뒤에 새1장을 넣어24장×2F=48F. 후진은 같은 순환을 역방향으로 읽는다. 대기는 `idle-0 → idle-in → idle-1 → idle-out`, 8/7/8/7F로 기존30F를 유지한다.
- 점프의 시간 진행률은 `(vy+800)/1600`이며 그림 자체를 회전한 복제품으로 세지 않는다. 새 접기/펼치기 원화와 연속 각도 `이륙방향 × 360 × 진행률`을 결합한다. 논리 발 좌표는 그대로, 그림 원점만 중심(256,256), 표시y는 논리y-120으로 옮겨 같은 월드 위치를 기준으로 회전한다.
- 이륙 뒤 F1~3 rise, F4~5 lift, F6~9 fold, F10~16 tuck, F17~28 coil, F29~32 tuck, F33~36 release, F37~40 open, F41~44 fall, F45~47 landing. F48 착지에는 360°와 같은0°로 복귀하고 상대 방향을 본다. 초반에 몸을 일찍 접어 수평으로 눕기 전에 작은 윤곽으로 전환한다. 이 시간표는 H1의 기존48F 점프에 맞춘 그림 선택이며 수직 적분이나 이동거리를 바꾸지 않는다.
- 공중 피격에서는 회전을 끊고 기존 피격 자세를 우선한다. 경직이 먼저 끝나더라도 그 점프가 착지할 때까지 다시 회전하지 않는다. KO는 기존 결과 자세를 우선한다.
- 공격 준비는3그림, 회복은4그림(선 강발6그림)을 기존 구간 안에서 균등 분할한다. 새 그림의 실제 자세를 검수해 약손/약발 준비 중간은 기존 extend 뒤, 강손/강발 준비 중간은 기존 extend/lift 앞에 둔다. 회복 중간은 retract 다음이다. 유효 그림은 기존1장과 기존age를 그대로 쓴다.

|---|---|---|---|---|
| 선/앉은 약손 | 2/2/2 | 3 | 4/4/4/3 | 24 |

- 지상 hit 경직 잔여4~0은 settle 그림, 공중 hit는 기존 그림이다. 추가 움직임/피해 면제는 없다. KO는 기존0/6/12F 주요 자세 사이의3~5F와9~11F에 새 그림을 넣고 결과 대기18F는 유지한다.
- 메치기는 H17~19 turn-mid, H24~27 drop-mid, 대상H48~53 rise-mid를 넣는다. 풀린 공격자의 T2~3에는 release-mid를 넣는다. H36 충돌·H54/72 복귀·T12 복귀와 풀기 창은 기존 그대로다.
- 렌더는 직전/현재 논리틱 위치·회전을 누적시간 비율로 보간한다. 그림의 attack age와 사건은 현재틱을 따른다. 최대1F의 표시 이력을 쓰며 행동/방향/자세/접지/잡기 관계 변경, 타격/잡기 사건, 그림 원점 변경, 정지/초기화/종료 경계는 양쪽을 현재값에 맞춘다. 판정은 보간 좌표를 읽지 않는다.
- `smooth-v1`은 기존 원화 참조 비율384/1120, 나머지3개 새 묶음은 정렬된512 참조를 생성1254로 재현한 공통 비율512/1254를 쓴다. 모두 최종512, 표시.625이며 포즈별 bbox 확대/축소나 픽셀 색/알파 수정은 하지 않는다. 지상은 실루엣 발/몸 하단448, flip은 캔버스 가상 지면448을 쓴다.
