# H1 전투 포즈 원화

2026-10-01. 내장 ImageGen으로 제작한 시안이다. 원본25장과 재생성3장을 보존한다. 최종 게임용 외형 승인을 뜻하지 않는다.

- `prompts.json`: 최초25장의 정확한 프롬프트·기준 이미지·도구 출력 경로. 비동기 완료 순서 대신 도구가 반환한 포즈 이름과 파일 경로를 대조했다.
- `retry-prompts.json`: 앉은 약손 회복·강손 준비의 과도한 확대와 앉은 강발 준비의 발 뻗음을 수정한3장의 정확한 프롬프트. 해당3장은 `-v2.png`를 선택하고 기존 후보도 보존한다.
- 파생 출력은 `../../derived/combat-v1/manifest.json`의 source 항목을 따른다. 공통 배율384/1120, 루트(256,448), 512×512 RGBA. 몸이나 팔다리를 코드로 다시 그리지 않았다.
- 남은 품질 문제: 선 발차기에서 지지발 위치와 상체 높이가 포즈마다 다르며 걷기/공격 전환의 흔들림이 있다. 실제 타격점과 손·발 윤곽의 세밀한 일치는 추가 검수 대상이다.

기준 이미지와 이전 v1/v2/movement-v1은 그대로 보존한다.
