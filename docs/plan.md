# 작업 계획

현재 작업(2026-10-03): 사용자가 잡기를 회전 메치기·바닥 충돌·다운·기상으로 고치고 잡히는 순간의 U+I 풀기를 넣도록 요청했다. [메치기 수정 명세](specs/h1-throw-revision.md)의 “권장 시간표로 수정”을 승인받아 H36 피해18·공격자H54/대상H72 복귀와 H0~12 풀기를 반영했다. 기존94포즈를 보존하고6포즈를 더해100포즈를 사용한다. 효과음보다 이 수정과 실제 체감 검수를 먼저 진행한다.

현재 검증: H0 즉시 풀기·H0 단독 손의3F 조합·사전 입력 제외, 타격 우선/동시 유효 잡기, H36 충격·H54/72 독립 복귀, 다운 타격/잡기 차단과 H72 정상 판정, 정지/마지막 틱/KO·종료 포즈를 자동 검사했다. 전체174개·타입/빌드·100포즈 에셋 검사를 통과했다. 빌드 화면의 근접 배치 이후 실제 U+I로 피해18의 메치기, 표적의 일회 풀기와 PLAYER 직접 풀기 피해0을 확인했다. 정확한 범위와 근거는 [메치기 검수 기록](reviews/h1-throw-revision.md)을 따르며 사람 체감·독립 Chrome/Edge 확인은 남는다.

직전 G 이력(2026-10-03): [G1~G4 잡기와 풀기](specs/h1-grab.md)의 밀치기·H18/30/36 시간표는 위 메치기 수정으로 대체했다. 당시 기존75+잡기19=94포즈와 자동162개 검사 결과·브라우저 확인 한계는 [이전 G 검수 기록](reviews/h1-grab.md)에 보존한다.

직전 완료(2026-10-03): 승인된 [C 콤보](specs/h1-combat-expansion.md)의 선 U→I→J 예약/명중 회복 취소를 경기·표적 화면에 연결했다. 기존93+콤보18=111개 테스트·타입/빌드·75포즈 에셋 검사를 통과했다. 실제 키로 가까운3타 피해30과 중간 거리2타 피해20을 확인했다. [콤보 검수 기록](reviews/h1-combo.md)에 거리/입력 경계와 실제 화면 근거·미확인 체감을 구분했다.

직전 완료(2026-10-02): 승인된 [H1 AI 대전 v0.1](specs/h1-ai-match.md)을 `match.html`에 연결했다. CPU의 접근·기본기 순환·방어와 60초·2선승·재경기·재시작을 함께 플레이한다. 자동93개 검사와 실제 CPU2승·플레이어 반격·CPU 방어 확인 범위는 [AI 검수 기록](reviews/h1-ai-match.md)을 따른다. 표적 전투 검수는 `combat.html`에 유지한다.

추가 검수(2026-10-02): 빌드 경기의 실제 키 펄스로 PLAYER2:1 최종 승리를 확인했다. 지속 방어·사람의 난이도 체감·독립 Chrome/Edge 검증은 남는다. [검수 기록](reviews/h1-ai-match.md)에 반복 J와 D+J의 라운드 결과, S+A 펄스의 검증 한계를 구분했다.

승인·반영 범위: C 지정 예약/명중 회복 취소와 U+I·거리96·피해18·최대3F 손 대기는 유지하며 성공 동작은 회전 메치기로 바꾼다. 최종 이동48·앞방향 착지·위치 교대 없음, 풀기 분리16/복귀12F를 유지한다. 다운/기상 H36~71에는 일반 타격·잡기를 받지 않는다. 기존8공격 수치와 C 창·CPU 기본기 선택은 유지한다. 정지는 C 예약과 손 대기를 비우고 진행 상태를 보존한다. 종료는 실행 관계/잠금을 제거하고 마지막 포즈를 보존하며 라운드/초기화는 스냅샷도 비운다.

구현·검수 순서: 최신 기술 의도와 시간표 확정 → H0 풀기 및 다운·독립 복귀 → 회전/공중/바닥/기상 이미지와 표시 변환 → 두 전투 화면·근접 배치·연결 검수 화면 → 자동/타입/빌드/에셋 → 실제 키/모션 → 기록·커밋·push. 기술의 성공 동작·판정·상대 반응·실패·대응·회복을 함께 확인한다. 표적 일회 입력·근접 배치·자동 시나리오는 실제 이동 접근이나 사람의 키 조작 검사와 구분한다.

후속 대기: 사람의 메치기/풀기·입력·모션 체감, 실제 이동 접근과 정확한 H0 물리 입력 확인, 독립 Chrome/Edge 검수. H0 판정은 현재 자동 검사·연결 시나리오로 확인했다. [S 효과음 v0.1](specs/h1-sound.md)은 H36 바닥 충돌 사건에 연결 목표만 맞췄으며 제작/게임 연결은 계속 미승인이다. S1 합성9종 청취 시안 확인 → 음색/음량 선택 → S2 연결 순서이며 현재 게임은 무음이다. CPU의 콤보·잡기·풀기 전략 확대도 별도 승인 대상이다. 앉은 방어 유지 한계와 난이도 체감 검수는 계속한다.
