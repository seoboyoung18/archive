메치기 구현·검수 이력: 최신 기술 의도와 시간표 확정 → H0 풀기 및 다운·독립 복귀 → 회전/공중/바닥/기상 이미지와 표시 변환 → 두 전투 화면·근접 배치·연결 검수 화면 → 자동/타입/빌드/에셋 → 실제 키/모션 → 기록·커밋·push. 기술의 성공 동작·판정·상대 반응·실패·대응·회복을 함께 확인한다. 표적 일회 입력·근접 배치·자동 시나리오는 실제 이동 접근이나 사람의 키 조작 검사와 구분한다.

후속 검수: S2의 실제 출력 장치 청취·겹침/지연/왜곡과 독립 Chrome/Edge 확인, 실제 이동 접근·정확한 H0 물리 입력 검수. H0 판정은 현재 자동 검사·연결 시나리오로 확인했다. 진행 승인이나 자동 결과를 미검증 입력/모션/난이도·음질 전체의 품질 승인으로 확대하지 않는다. 승인된 AI-G에서 앉은 방어 대응·반복 잡기 풀기를 검수하며 난이도 체감은 별도로 확인한다. CPU 콤보·점프·무작위·난이도 선택은 이번 범위 밖이다.
