# 캐릭터 기준
- H1: 검은 단발, 빨간 재킷과 흰 운동복, 검은 바지, 손 붕대, 빨간 운동화.
- B1: 주황색 호랑이, 남색 도복 바지, 손·발목 붕대, 줄무늬 꼬리.
- R3: 보라색 장갑판, 어두운 관절, 민트색 바이저와 관절 포인트.

오른쪽을 바라보는 전신 기본 전투 자세. 단일 기준 이미지이며 애니메이션 시트가 아니다.
원본은 보존하고 파생 동작은 별도 파일로 만든다.
엔진·화면 크기 결정 후 캔버스 규격, 발 기준점, 화면상 키, 프레임 수를 정한다.
현재 이미지 크기와 발 위치는 정규화되지 않았다. 이미지 여백·꼬리로 피격 범위를 자동 결정하지 않는다.

## 애니메이션 제작 방식 비교 · 제안
| 방식 | 제작 방법 | 준비 및 검증 |
|---|---|---|
| 프레임 교체 | 동작별 포즈 이미지를 순서대로 표시 | 포즈마다 얼굴·의상·비율·발 위치의 일관성 확인 필요 |
| 신체 파츠 기반 | 머리·몸통·팔다리 등을 분리해 관절을 움직임 | 현재 단일 이미지의 파츠 분리, 가려진 부위 보완, 관절 설정 필요 |

첫 H1 검증에는 소수 포즈의 프레임 교체 방식을 추천한다. 사용자 선택 전까지 확정하지 않는다.
현재 기준 이미지만으로 동작 애니메이션이 완성된 것으로 취급하지 않는다. 프레임 수·캔버스 규격·발 기준점·재생 시간은 후속 명세에서 정한다.
방식 참고: [프레임 애니메이션](https://docs.godotengine.org/en/4.4/tutorials/2d/2d_sprite_animation.html), [파츠 애니메이션](https://docs.godotengine.org/en/stable/tutorials/animation/cutout_animation.html). 이 참고 자료는 엔진 선정 결정을 의미하지 않는다.
