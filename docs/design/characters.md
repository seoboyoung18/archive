# 캐릭터 기준
- H1: 검은 단발, 빨간 재킷과 흰 운동복, 검은 바지, 손 붕대, 빨간 운동화.
- B1: 주황색 호랑이, 남색 도복 바지, 손·발목 붕대, 줄무늬 꼬리.
- R3: 보라색 장갑판, 어두운 관절, 민트색 바이저와 관절 포인트.

오른쪽을 바라보는 전신 기본 전투 자세. 단일 기준 이미지이며 애니메이션 시트가 아니다.
원본은 보존하고 파생 동작은 별도 파일로 만든다.
엔진·화면 크기 결정 후 캔버스 규격, 발 기준점, 화면상 키, 프레임 수를 정한다.
현재 이미지 크기와 발 위치는 정규화되지 않았다. 이미지 여백·꼬리로 피격 범위를 자동 결정하지 않는다.
