# 캐릭터 기준
2026-10-06 현재 H1은 [회전 점프·중간 그림](../specs/h1-smooth-flip.md)까지 145개 게임 포즈를 사용한다. B1/R3에는 단일 원본 기준 이미지와 이를 비율 유지 정렬한 [R0 검수 시안](../reviews/roster-r0.md)만 있다. 게임에 쓸 동작 그림과 선택 흐름은 [첫 3명 초안](../specs/initial-roster.md)에 구분했다. 아래의 “엔진·화면 크기 결정 후” 문장은 초기 문서의 이력이며 현재 엔진·H1 화면 규격은 이미 결정됐다.
- H1: 검은 단발, 빨간 재킷과 흰 운동복, 검은 바지, 손 붕대, 빨간 운동화.
- B1: 주황색 호랑이, 남색 도복 바지, 손·발목 붕대, 줄무늬 꼬리.
- R3: 보라색 장갑판, 어두운 관절, 민트색 바이저와 관절 포인트.

오른쪽을 바라보는 전신 기본 전투 자세. 단일 기준 이미지이며 애니메이션 시트가 아니다.
원본은 보존하고 파생 동작은 별도 파일로 만든다.
엔진·화면 크기 결정 후 캔버스 규격, 발 기준점, 화면상 키, 프레임 수를 정한다.
원본 이미지 크기와 발 위치는 정규화되지 않았다. R0 파생 시안만 512×512·발 기준점(256,448) 후보로 정렬했다. 이미지 여백·꼬리로 피격 범위를 자동 결정하지 않는다.

## 애니메이션 제작 방식 · 2026-09-30 확정
| 방식 | 제작 방법 | 준비 및 검증 |
|---|---|---|
| 프레임 교체 | 동작별 포즈 이미지를 순서대로 표시 | 포즈마다 얼굴·의상·비율·발 위치의 일관성 확인 필요 |
| 신체 파츠 기반 | 머리·몸통·팔다리 등을 분리해 관절을 움직임 | 현재 단일 이미지의 파츠 분리, 가려진 부위 보완, 관절 설정 필요 |

사용자 승인으로 소수 포즈의 프레임 교체 방식을 선택했다. 파츠 기반 방식은 이번 제작 방식에 포함하지 않는다.
현재 기준 이미지만으로 동작 애니메이션이 완성된 것으로 취급하지 않는다. 프레임 수·캔버스 규격·발 기준점·재생 시간은 후속 명세에서 정한다.
방식 참고: [프레임 애니메이션](https://docs.godotengine.org/en/4.4/tutorials/2d/2d_sprite_animation.html), [파츠 애니메이션](https://docs.godotengine.org/en/stable/tutorials/animation/cutout_animation.html). 이 참고 자료는 엔진 선정 결정을 의미하지 않는다.

H1의 캔버스·발 기준점·포즈 수·공격 구간 연결에 대한 상세 제안은 [H1 애니메이션 명세 초안](../specs/h1-animation-draft.md)을 따른다. 수치와 실제 파생 이미지의 정합성은 제작 후 검증한다.
공격은 선/앉은 자세 각각 4종으로 확정됐다. 앉기·앉은 방어·앉은 피격을 포함한 41포즈 계획과 512×512·발 기준점 (256,448) 규격이 승인됐다. 공중 공격 이미지는 제작 범위에서 제외한다.
