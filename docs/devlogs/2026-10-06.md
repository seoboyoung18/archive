## B1/R3 R0 기준 자세 정렬과 비교

- 사용자 “좋아 계속 진행하자”를 [초안](../specs/initial-roster.md)의 R0 시안 제작 승인으로 받아 원본 `reference.png` 두 장을 보존하고 `scripts/normalize-roster-reference.ps1`로 512×512 투명 후보를 만들었다. 부위를 새로 그리거나 전투 에셋에 연결하지 않았다.
- 첫 정렬에서 B1 발이 기준선보다 약 8px 높았다. 원본의 알파>0 끝이 보간 후 거의 보이지 않는 테두리가 되기 때문이다. 최종 출력의 알파≥8 발끝을 y447에 맞추는 2차 배치로 수정했다. B1은 +8px, R3는 +2px 보정했다. 두 원본/출력의 해시와 경계는 각 `derived/r0/manifest.json`에 기록했다.
- [R0 검수 기록](../reviews/roster-r0.md)과 1280×720 [비교 화면](../reviews/evidence/roster-r0.html)·화면 증빙을 만들었다. 내장 PC 브라우저에서 세 이미지가 512×512로 로드되고 같은 지면에 표시됨을 확인했다. 비교 탭 경고·오류 로그는 없었다. 스크립트 재실행 시 출력 SHA가 같고 원본 SHA가 유지됐다. `npm run build`의 타입/빌드가 통과했고 기존 청크 크기 경고는 유지됐다. 게임 코드·입력·AI·수치는 변경하지 않았으며 게임 테스트는 R0의 검증 근거로 사용하지 않는다.
- 미확인: 사람의 외형·크기 승인, B1/R3 동작/판정/대전, 능력치·CPU 선택·효과음 공유 결정. 다음은 R0 그림 검수 후 B1의 도달 상태별 포즈 목록을 승인받는 것이다.
