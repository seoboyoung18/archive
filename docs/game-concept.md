# 차원격투 기획
## 확정
- 여러 세계의 인간·비스트·로봇이 모여 싸우는 2D 격투게임.
- 애니메이션풍 외곽선과 셀 명암.
- 최초 선택 캐릭터: H1 빨간 재킷 인간, B1 호랑이, R3 보라색 로봇. 이후 확장.
- 이미지와 기획을 먼저 준비하고 SDD 방식으로 개발.
- 저장소: https://github.com/seoboyoung18/dimension-fight
- 첫 버전 실행 플랫폼: PC 브라우저. 우선 키보드로 조작한다.
- 첫 버전 대전 방식: 플레이어 대 AI의 1인용 대전만 제공한다. 로컬 2인 대전은 첫 버전에 포함하지 않는다.
- 소수 포즈의 프레임 교체 애니메이션으로 시작한다.
- 경기장 1개, WASD 방향 조작·점프·약손·강손·약발·강발 공격·뒤 방향 방어·피격·쓰러짐. 전용 방어키는 두지 않는다.
- 3판 2승제로 먼저 2라운드를 이긴 쪽이 경기에서 승리한다. 라운드 시간 초과 시 체력이 적은 쪽이 패배한다.
- 시간 초과 시 동일 체력 또는 동시 KO면 승수 변화 없이 해당 라운드를 재경기한다. 예외적으로 실제 진행 횟수는 3회를 넘을 수 있다.
- 체력바·제한 시간·승패·재시작을 제공한다.
- H1 대 H1 AI로 전투 흐름부터 검증하고 B1/R3와 캐릭터 선택을 적용한다. 첫 버전의 최종 목표는 선택 캐릭터 3명이다.
- 공통 전투 처리와 캐릭터 데이터를 분리한다.
- 기술은 일반 격투게임의 성공 동작·판정·상대 반응·실패·대응 수단·회복을 함께 설계하고 검수한다. 메치기는 회전·바닥 충돌·다운·기상까지 표현해 잡기 풀기와 구분한다. 특정 게임의 수치나 규칙까지 자동으로 채택하지 않는다.
- 공격키는 U 약손·I 강손·J 약발·K 강발. 선 자세 4개와 앉은 자세 4개를 제공하고 공중 공격은 이후로 미루며 공중 방어는 제외한다.
- 약/강 손·발은 서로 반대 팔다리를 쓴다. 강공격은 지지발·골반·허리·상체가 함께 돌아가며 회수 후 기본 자세로 복귀한다.
- 선 강발은 다리가 완전히 펴진12~15F에 신발 앞부분에서 타격하며 내려오는16F 이후에는 추가 타격하지 않는다. 준비12/유효4/회복36F·총52F·피해16을 유지한다. 발 아래의 판정은 제거해 같은 지면의 앉은 상대는 비접촉으로 피한다.
- S 유지로 앉기, 뒤로 선 방어, S+뒤로 앉은 방어. 일반 공격은 두 자세 모두 방어, 중단은 선 방어만, 하단은 앉은 방어만 가능하다.
- H1 전투 명세 v0.3을 초기 구현 기준으로 확정했다. 체력 100·라운드당 60초, 다음 라운드는 Enter/버튼으로 시작한다. 공격 8종의 높이·수치·입력·자세 전환·AI는 명세를 따른다.
- 경기 진행 v0.2를 승인했다. 별도 표적 경기 화면에서 카운트다운 없이 수동 시작하며, KO18F 이후 다음 행동을 허용한다. TIME UP/DOUBLE KO와 최종 승패를 구분하고 Enter로 다음 라운드·재경기, R로 경기 전체를 초기화한다. AI는 후속 연결이다.
- 후속 AI 대전 v0.1을 승인했다. `match.html`의 CPU를12F 공개 상태 판단·닿는 기본기8종 순환·뒤 방향 방어로 연결한다. 선 방어/후진에 하단 우선, 앉은 상대에게 선 강발 제외. 점프·난이도 선택은 추가하지 않는다. 표적 검수는 `combat.html`에 유지한다.
- 2026-10-03 [전투 확장 C](specs/h1-combat-expansion.md)를 승인·구현했다. 선 U→I→J 한 경로에서 지정 다음 키를1개 예약하고 비방어 명중 때만 정해진 회복 창을 취소한다. 기존 피해8/12/10·밀려남·사거리·공격 구간을 유지해2타20·3타30이며 중앙3타는 첫 U 접촉 거리110 미만에서 가능하다. CPU는 기존 기본기 전략을 유지하고 새 콤보를 선택하지 않는다. [검수 기록](reviews/h1-combo.md)에 자동111개 검사와 실제 입력 결과·남은 체감 검수를 구분한다.
- 2026-10-03 [회전 메치기 수정](specs/h1-throw-revision.md)의 “권장 시간표로 수정”을 승인·반영했다. 지상 선 자세에서3F 이내 새 U/I 겹침으로 거리96 이하의 선/앉은 대상을 잡는다. H0~12 풀기 뒤 H13~35 회전·들어 넘기기·낙하, H36 바닥 충돌·피해18·최종 이동48, 공격자H54·대상H72 복귀다. 앞방향 착지이며 좌우 위치를 바꾸지 않는다. 다운/기상 중인 H36~71 대상은 일반 타격·잡기를 받지 않고 H72부터 정상 판정이다. 새 다운공격·낙법·기상 공격은 추가하지 않는다.
- 잡히는 H0의 새 U+I도 즉시 풀리며 H0의 새 한 손은 H1~3 안에 반대 손과 조합할 수 있다. 풀기는 H12까지, H13부터 실패하며 H 이전 유지키·반복·사전 입력은 제외한다. 풀기/동시 유효 잡기는 피해0·양쪽16 분리·12F 복귀다. 선 단독 손 최대3F 대기·조기 놓기 즉시 실행과 C의 실제 공격age 기준 창·후속 입력 지연 없음은 유지한다. 기존94포즈를 보존하고 메치기6포즈를 추가해100포즈를 사용한다. 바닥 충돌 KO는 메쳐진 최종 자세를 유지한다. 검사 수·자동/실제 검수 범위는 [메치기 검수 기록](reviews/h1-throw-revision.md)을 따르며 사람 체감과 독립 Chrome/Edge 확인은 남는다.
- 2026-10-03 사용자가 메치기 결과에 “좋다 다음 계속해서 진행하자”라고 답해 [S1 효과음 청취 시안](specs/h1-sound.md) 제작으로 진행한다. 직접 합성한 손발4종·방어·헛침·붙잡음·바닥 충격·풀기 WAV9종과 별도 `sound.html`이 이번 범위다. 전투 수치·CPU 전략과 전투 화면의 무음 상태는 유지한다. 메치기 결과 확인을 독립 Chrome/Edge·전체 입력/난이도 체감 검증 완료로 확대하지 않는다.
- S1은 개별9종·전체·콤보0/13F/24F·같은 강손 동시2회·H36 메치기·H12 풀기·H0 단독 풀기를 버튼으로 비교한다. 시안 초기 음량30%, 새 버튼의 기존 청취 교체, 정지·포커스 이탈·탭 숨김·음량0의 소리/예약 폐기를 적용한다. 시안 파형·길이·진폭은 비교용 제작값이며 게임의 최종 음색/음량 선택은 아니다.
- 첫 검증 대상은 Windows PC의 Chrome·Edge, 논리 화면은 1280×720이다. 실제 버전과 동작 적합성은 실행 검증 때 기록한다.
- 기술 구성은 Phaser 4 + TypeScript + Vite다. H1은 512×512 PNG·발 기준점 (256,448)·기본 표시 키 240·41포즈를 제작 기준으로 삼고 먼저 대기·약손 시안을 검수한다.
## 기획 결정 필요
B1/R3의 능력치 차별화와 캐릭터 선택 상세 흐름. H1 전투의 초기 기준은 [H1 전투 명세](specs/h1-combat-draft.md)에 기록한다.
AI의 현재 구현 기준은 승인된 [AI 대전 v0.1](specs/h1-ai-match.md)이다. 실제 난이도/재미와 앉은 방어 유지 한계에 대한 보완 방향은 별도 검토한다.
온라인·필살기·성장·로그인·DB는 현재 확정 범위에 포함되지 않는다.
2026-10-01의 정해진2~3타 연계와 U+I 잡기 방향은2026-10-03 C 및 G1~G4 상세 승인으로 구체화했다. [S 효과음 v0.2](specs/h1-sound.md)의 S1 시안은 제작했고 자동 검사와 내장 브라우저 재생 상태를 확인했다. 실제 탭 전환·브라우저 오류 재현·독립 Chrome/Edge·출력기기 청취는 미확인으로 남긴다. 상세 검증 결과와 확인 범위는 [S1 검수 기록](reviews/h1-sound-preview.md)을 따른다. 최종 음색·길이·상대 음량·게임 기본 소리 활성 여부와 초기 음량은 청취 후 선택한다. S2의 사건 연결과 실패 잡기 무음·마지막 결과 타격음 완료·Web Audio 우선 지원은 후속 범위다. S1 시안이나 수치 검사를 실제 게임 오디오·사람의 청취 품질 통과로 간주하지 않는다. CPU의 콤보·잡기·풀기 선택 확대는 별도 확인 대상이며 기존 기본기 전략을 유지하므로 PLAYER의 앉은 방어 유지 한계도 남는다.
