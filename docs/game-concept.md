# 차원격투 기획
## 확정
- 여러 세계의 인간·비스트·로봇이 모여 싸우는 2D 격투게임.
- 애니메이션풍 외곽선과 셀 명암.
- 최초 선택 캐릭터: H1 빨간 재킷 인간, B1 호랑이, R3 보라색 로봇. 이후 확장.
- 이미지와 기획을 먼저 준비하고 SDD 방식으로 개발.
- 저장소: https://github.com/seoboyoung18/dimension-fight
## 제안
- 첫 목표는 소수 프레임 애니메이션을 사용하는 1인용 AI 대전.
- 경기장 1개, 이동·점프·공격 2종·방어·피격·쓰러짐.
- H1 전투부터 완성하고 B1/R3 적용. 공통 전투 로직과 캐릭터 설정 분리.
## 기획 결정 필요
실행 플랫폼, 엔진/언어, 대전 방식, 조작키, 승패·무승부·라운드 규칙, 전투 수치,
캐릭터별 차별화 및 애니메이션 규격/제작 방식.
온라인·콤보·필살기·성장·로그인·DB는 현재 확정 범위에 포함되지 않는다.
