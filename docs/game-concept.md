# 차원격투 기획
## 확정
- 여러 세계의 인간·비스트·로봇이 모여 싸우는 2D 격투게임.
- 애니메이션풍 외곽선과 셀 명암.
- 최초 선택 캐릭터: H1 빨간 재킷 인간, B1 호랑이, R3 보라색 로봇. 이후 확장.
- 이미지와 기획을 먼저 준비하고 SDD 방식으로 개발.
- 저장소: https://github.com/seoboyoung18/dimension-fight
- 첫 버전 실행 플랫폼: PC 브라우저. 우선 키보드로 조작한다.
- 첫 버전 대전 방식: 플레이어 대 AI의 1인용 대전만 제공한다. 로컬 2인 대전은 첫 버전에 포함하지 않는다.
- 소수 포즈의 프레임 교체 애니메이션으로 시작한다.
- 경기장 1개, WASD 방향 조작·점프·약손·강손·약발·강발 공격·뒤 방향 방어·피격·쓰러짐. 전용 방어키는 두지 않는다.
- 3판 2승제로 먼저 2라운드를 이긴 쪽이 경기에서 승리한다. 라운드 시간 초과 시 체력이 적은 쪽이 패배한다.
- 시간 초과 시 동일 체력 또는 동시 KO면 승수 변화 없이 해당 라운드를 재경기한다. 예외적으로 실제 진행 횟수는 3회를 넘을 수 있다.
- 체력바·제한 시간·승패·재시작을 제공한다.
- H1 대 H1 AI로 전투 흐름부터 검증하고 B1/R3와 캐릭터 선택을 적용한다. 첫 버전의 최종 목표는 선택 캐릭터 3명이다.
- 공통 전투 처리와 캐릭터 데이터를 분리한다.
- 공격키는 U 약손·I 강손·J 약발·K 강발. 선 자세 4개와 앉은 자세 4개를 제공하고 공중 공격은 이후로 미루며 공중 방어는 제외한다.
- S 유지로 앉기, 뒤로 선 방어, S+뒤로 앉은 방어. 일반 공격은 두 자세 모두 방어, 중단은 선 방어만, 하단은 앉은 방어만 가능하다.
## 기획 결정 필요
지원 브라우저·버전과 화면 기준, 엔진/언어, 자세 전환·동시 입력 세부, 공격별 높이 분류, 라운드 시간·전투 수치,
캐릭터별 차별화 및 애니메이션 규격·프레임 수. 상세 제안은 [H1 전투 초안](specs/h1-combat-draft.md)에 기록한다.
온라인·콤보·필살기·성장·로그인·DB는 현재 확정 범위에 포함되지 않는다.
