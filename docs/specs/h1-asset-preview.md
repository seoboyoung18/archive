# H1 에셋 시안·실행 환경 작업 명세

전제: H1 전투 v0.3, 이미지 규격, Phaser 4 + TypeScript + Vite 및 스크립트 정렬 사용을 사용자가 승인했다.

## 이번 범위
- 기존 문서·원본을 보존하며 npm 실행/타입 검사/빌드와 .gitignore를 준비한다.
- H1 대기 1장, 선 약손 준비·유효·회복 3장을 ImageGen으로 생성한다. 생성 원화·프롬프트·정렬 결과를 따로 저장한다.
- 스크립트는 비율 유지 축소와 투명 캔버스 배치만 수행한다. 창작 수정·얼굴/의상/포즈 덧그리기는 하지 않는다.
- Phaser 시안 화면에서 네 포즈 선택, 약손 6F/3F/15F 반복 미리보기, 좌우 반전, 발 기준점·피격/유효 공격 사각형 표시를 제공한다.
- 시안 화면은 게임 완료 화면이 아니다. 대전·피해·AI·승패 구현은 이 작업의 범위 밖이다.

## 완료 조건
- 고정 의존성 설치, 타입 검사, 정적 빌드 성공. README에 실행·검증 명령 기록.
- 원본 SHA 불변, 출력 4장 각 512×512 RGBA, 투명 배경, 발 기준점 (256,448), 기본 키 384 원화 픽셀(표시 시 240).
- 변환 과정과 기준점을 manifest에 기록하고 자동 검사로 크기·투명도·경계 잘림·파일 참조를 확인한다.
- 브라우저에서 시안 로딩·포즈 선택·재생·반전·판정 표시를 확인한다. 실제 확인한 브라우저와 한계를 기록한다.
- 외형·몸 비율·발 흔들림·공격 그림과 판정 정합성을 시각적으로 검사한다. 불일치가 남으면 완성 스프라이트로 승인하지 않고 시안 상태로 보존한다.
- 결과와 미확인 사항은 개발일지에 기록하고 기능별 커밋으로 보존한다.
