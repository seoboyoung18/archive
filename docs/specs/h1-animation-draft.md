# H1 애니메이션 명세 v0.3 · 제작 기준

상태: **2026-09-30 사용자가 규격·41포즈 계획을 승인했다. 타이밍은 승인된 전투 v0.3을 따른다.** 시안 생성 결과는 실제 검수 후 완성 여부를 기록한다.
원본은 `assets/characters/h1/reference.png`이며 보존한다. 대기·약손 시안 4장부터 제작하고 나머지는 시안 검수 후 확대한다.
전투 시간과 상태는 [H1 전투 초안](h1-combat-draft.md)을 기준으로 한다.

## 1. 외형·이미지 규격
- 검은 단발·얼굴·빨간 재킷·흰 운동복·검은 바지·붕대·빨간 운동화 및 체형을 기준 이미지와 일치시킨다.
- 동작별 개별 RGBA PNG, 투명 배경, 오른쪽 방향. 전체 제작 시 파일 위치는 `assets/characters/h1/derived/<버전>/<동작>/<순번>.png`를 사용한다. 시안은 `v1`의4장과 `v2`의8장을 보존한다. v2는 `idle/startup/active/recovery.png`, `crouch/crouch-startup/crouch-active/crouch-recovery.png`와 manifest로 관리한다. 생성 원화는 같은 버전의 `generated`에 보존한다.
- 한 포즈 캔버스 512×512. 고정 발 기준점 (256,448). 좌표 원점은 캔버스 왼쪽 위다.
- 기본 대기 자세의 정수리~지면 높이 384픽셀을 목표로 원본 비율을 보존해 정렬한다. 게임 표시 배율 0.625, 기본 표시 키 240 논리 픽셀이다. 움직일 때마다 몸의 바운딩 박스에 맞춰 재확대하지 않는다.
- 두 발이 땅에 닿는 포즈의 지면을 y=448에 맞춘다. x=256은 몸 중심의 지면 투영 기준이다. 점프 포즈도 가상의 같은 기준점을 사용하고 실제 높이는 전투 좌표로 이동한다.
- 좌향은 발 기준점을 중심으로 전체 포즈를 반전한다. 그림마다 재계산한 중앙이나 투명 여백을 기준으로 반전하지 않는다.
- 팔·발·머리카락이 캔버스 밖으로 잘리면 해당 포즈를 승인하지 않는다. 임의 축소로 해결하지 않고 규격과 판정의 관계를 다시 검토한다.
- 쓰러짐 그림은 신체가 지면 y=448에 놓이도록 그린다. 원본, 파생 원화, 게임용 정렬 결과는 덮어쓰지 않고 구분한다.

## 2. 최소 포즈 구성
시간 F는 1/60초 논리 시간이다. 같은 포즈를 여러 F 유지하며, 포즈 수가 공격 길이를 결정하지 않는다.

| 동작 | 고유 포즈 수 | 표시 규칙 |
|---|---|---|
| 대기 | 2 | 각 15F 반복 |
| 걷기 | 4 | 각 6F 반복, 뒤로 이동할 때도 같은 주기 사용 |
| 점프 | 3 | 상승(vy < -100) / 정점(-100≤vy≤100) / 하강(vy > 100), 착지 시 지상 상태 포즈 |
| 약손 | 3 | 준비 6F / 타격 3F / 회복 15F |
| 강손 | 3 | 준비 10F / 타격 3F / 회복 21F |
| 약발 | 3 | 준비 8F / 타격 4F / 회복 18F |
| 강발 | 3 | 준비 24F / 타격 4F / 회복 24F |
| 선 방어 | 1 | 방어 경직 동안 유지, 뒤 방향 유지 중 평상시에는 후진 걷기 표시 |
| 피격 | 1 | 선 피격 경직 동안 유지, 공중에서도 같은 포즈 |
| 쓰러짐 | 3 | 각 6F, 총 18F 후 마지막 포즈 유지 |
| 앉기 | 1 | S 유지, S+앞/뒤에서도 같은 기본 앉기 포즈 |
| 앉은 방어 | 1 | S+뒤 입력으로 일반/하단 방어 성공 시 경직 동안 표시 |
| 앉은 피격 | 1 | 앉은 채 맞으면 경직 만료까지 유지 |
| 앉은 약손 | 3 | 준비 6F / 타격 3F / 회복 15F |
| 앉은 강손 | 3 | 준비 10F / 타격 3F / 회복 21F |
| 앉은 약발 | 3 | 준비 8F / 타격 4F / 회복 18F |
| 앉은 강발 | 3 | 준비 14F / 타격 4F / 회복 24F |
| 합계 | 41 | 선/앉은 공격 8종과 자세별 방어·피격 포함. 공중 공격 포즈 제외 |

- 공격 상태 나이에 따라 포즈를 선택한다. 렌더 시간만으로 별도 공격 애니메이션을 돌려 판정과 어긋나지 않게 한다.
- 공격 취소 시 맞은 자세의 피격 포즈, 체력 0이면 쓰러짐 포즈로 전환한다. 선/앉은 자세 모두 쓰러짐 3포즈를 공유하는 안이며 제작 시 전환의 자연스러움을 확인한다. 경기 일시정지 시 포즈 진행도 멈춘다.
- 라운드 승리/시간 종료 선수는 마지막 포즈를 유지한다. 별도 승리·패배 포즈는 41개에 포함하지 않는다. 다음 라운드·동률 재경기에는 포즈 시간을 초기화한다.
- 앉은 동작도 (256,448) 발 기준점을 유지하고 캔버스나 표시 배율을 바꾸지 않는다. 자세 변경 때 몸 전체를 선 자세 키에 맞춰 확대하지 않는다.
- 점프 그림 자체를 캔버스 위로 이동시켜 점프 높이를 중복 적용하지 않는다.

## 3. 제작·검수 순서
1. 기준 이미지에서 발·머리 위치를 확인하고 대기 포즈 1장으로 정규화 시안을 만든다.
2. 약손 3포즈를 제작해 얼굴·몸 비율·발 고정과 전투 판정의 관계를 검토한다.
3. 적합하면 앉기 1장과 앉은 약발 3포즈로 낮아진 피격 범위·하단 타격의 정합성을 검토한 다음 나머지를 제작한다. 초기 시안 검토 전 전량을 만들지 않는다.
4. 애니메이션별 연락판과 반복 재생 미리보기로 외형·흔들림·잘림을 확인한다.
5. 게임 표시 크기에서 좌우 방향과 공격/피격 사각형을 겹쳐 확인한다. 공격의 유효 포즈에서 주먹·발의 접촉 위치가 판정과 크게 어긋나면 이미지 또는 제안 판정을 함께 수정한다.

## 4. 완료 조건 · 제작 후 검증 예정

초기 4장 시안의 실제 결과는 [검수 기록](../reviews/h1-preview.md)을 참고한다. 아래 조건은 전체 41포즈의 완료 조건이며 현재 달성된 것으로 보지 않는다.

후속 보완과 앉은 약발을 포함한8포즈 결과는 [v2 검수 기록](../reviews/h1-crouch-preview.md)에 있다. 기존 버전과 후보 재생성을 중복 포즈로 집계하지 않는다.
- 원본 Git blob 불변. 파생 PNG의 실제 크기·알파 채널·파일 수·동작 이름 일치.
- 기본 표시 키 240, 발 기준점 (256,448), 이동/대기 전환 시 의도하지 않은 발 미끄러짐 없음.
- 오른쪽 원화와 왼쪽 반전에서 발 기준점 및 판정 사각형 관계 일치.
- 얼굴·의상·색상·비율 일관성, 하얀 배경·테두리 잔여물·잘린 팔다리 없음.
- 선 약손/강손/약발/강발 24/34/30/52F, 앉은 약손/강손/약발/강발 24/34/30/42F의 구간과 포즈 전환 일치. 그림 재생 때문에 중복 피해가 발생하지 않음.
- 캔버스 규격 승인과 실제 이미지 검수는 구분한다. 시안 검수 결과와 남은 제작량은 개발일지에 기록한다.
