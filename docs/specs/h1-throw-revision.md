# H1 일반 잡기 · 회전 메치기 수정

후속 표시 보완: 아래 최초 구현의 대상136~1144 고정 보정과 기상 복귀 보간은 [대기·방어·잡기 코너 표시 명세](h1-grab-edge.md)의 실제 알파 경계/쌍 공통 이동으로 대체한다. 기본 연출 곡선·높이·회전과 승인된 전투 시간표는 유지한다.

2026-10-03 · 사용자 수정 요청 및 권장 시간표 승인·구현. 이전 [G 명세](h1-grab.md)의 붙잡고 밀치는 동작을 **붙잡기 → 몸을 돌려 들어 넘기기 → 바닥 충돌 → 쓰러짐 → 기상**으로 바꿨다. 잡기 성공과 풀기는 시각적으로 명확히 다르게 보이게 한다. [검수 결과](../reviews/h1-throw-revision.md)에 자동/브라우저 확인과 최종 체감 미확인을 구분한다. 효과음 제작보다 이 수정을 먼저 진행했다.

## 확정된 수정 방향

- 일반 격투게임의 기술로 이해하고 제작한다. 성공 동작·판정·상대 반응·실패·대응 수단·회복을 한 기술로 함께 확인하며, 단순히 붙잡았다 놓는 모션으로 메치기를 대체하지 않는다.
- U+I 잡기, 거리96·피해18·손 조합3F는 유지한다. 실제 잡히는 프레임H0에 대상의 새 U+I 조합이 완성되면 즉시 풀기(피해0). H0에 새로 누른 한 손도 H1~3의 반대 손과 조합할 수 있다. 기존 H+1~12 풀기도 유지한다. H 이전부터 누른 키·반복 입력은 새 풀기로 인정하지 않는다.
- 양쪽 유효 잡기가 동시에 닿는 기존 상쇄는 유지한다. H0 풀기도 양쪽 분리/풀기 동작으로 표현하며 성공 메치기와 다르게 보인다. 타격 접촉 우선은 유지한다.
- 회전·공중으로 넘겨짐·바닥 충돌·살아 있는 기상 그림을 추가한다. 바닥 충돌 KO는 다시 서서 쓰러지는 기존 KO 그림으로 돌아가지 않고 메쳐진 자세를 유지한다.
- CPU의 새 잡기/풀기 선택과 효과음은 이번 요청으로 추가 승인하지 않는다. 표적 검수의 공통 입력으로 풀기를 확인한다.

## 시간표 · 사용자 승인

사용자가 “권장 시간표로 수정”을 선택했다. 기존 피해시점H+18·대상해제H+30을 아래 권장안으로 변경한다. 기존값 열은 이전 구현과의 비교이며 더 이상 구현 기준이 아니다.

| 단계 | 권장 시간표 | 기존 수치를 유지할 경우 |
|---|---|---|
| 붙잡힘/풀기 | H0~12 | H0~12 |
| 회전·들어 넘기기·낙하 | H13~35 | H13~17 |
| 바닥 충돌·피해18 | H36 | H18 |
| 공격자 회복 완료 | H54 | H36 |
| 대상 다운·기상 완료 | H72 | H30 |

승인안은 잡은 뒤0.6초에 바닥 충돌,0.9초에 공격자 행동 복귀,1.2초에 대상 기상 완료다. 대상은 다운/기상 잠금 중 일반 타격·잡기를 받지 않으며 H72부터 정상 판정으로 복귀한다. 추가 다운공격/낙법/기상 공격은 넣지 않는다. 메치기는 앞쪽으로 떨어뜨려 현재 좌우 위치 순서를 유지한다. 거리·피해·최종 이동량48과 탈출 분리16/복귀12F는 유지한다. 충돌 전 풀기/시간 종료면 피해는 없다.

## 설계·검증

순수 전투는 H0 풀기 조합을 입력 읽기 단계에서 보존하고 잡기 성립 후보 해결 때 우선 소비한다. H0의 앉은 대상도 같은 새 U+I로 풀 수 있게 확인한다. 이전부터 준비 중인 잡기나 오래 유지한 손을 새 풀기로 바꾸지 않는다. H+12/13, 동시에 두 유효 잡기, 동일 틱 일반 타격, 정지/재개 경계를 회귀 검사한다.

양쪽 회복 시점은 각각의 잠금 기한으로 관리한다. 권장안에서는 공격자가 먼저 풀리므로 한쪽 해제로 다른 쪽을 해제하거나 진행 관계가 영구 잔류하지 않게 한다. 결과는 실행 관계를 제거하고 마지막 포즈를 보존한다. 시간 종료는 그 틱 이전에 아직 하지 않은 메치기를 추가 진행하지 않는다.

이미지는 내장 ImageGen으로 제작하고 기존 원본은 보존한다. 회전 피격자의 공중 루트와 바닥 접촉 루트를 명시하고, 화면 표시 변환을 판정 위치와 구분한다. 중앙/좌우/코너·선/앉은 대상·풀기·비KO 기상·KO를 실제 크기의 연결 화면에서 확인한다. 자동 판정 검사와 시각/실제 입력 검수를 구분해 보고한다.

채택한6포즈는 공격자 회전/들어 넘김/내려찍기와 대상 공중/바닥/기상이다. 실제 구간은 공격자H0~12 붙잡음,13~19 회전,20~27 넘김,28~44 내려찍기,45~53 복귀다. 대상은H0~19 붙잡힌 자세,20~35 공중 회전,36~47 바닥,48~59 기상,60~71 기존 선/앉은 회복,72부터 자유다. 코너의 넓은 바닥 그림은 표시 중심을136~1144 안에 두고 기상 중 논리 루트로 복귀한다. 이 표시 보정은 판정/최종 이동량48을 바꾸지 않는다.

표적 검수 화면에 공개된 근접 배치(루트500/584)를 추가한다. 근접 배치는 초기화된 검수 시작 위치만 바꾸고 성공·피해·풀기 상태를 주입하지 않는다. 별도 연결 검수 화면에서 동일 공통 전투를 정해진 입력으로 진행해1F 이동·재생을 제공한다. 실제 이동 접근 검수와 근접 배치 이후 키/동작, 검수 화면의 입력 시나리오를 구분한다. AI 경기의 초기 위치나 조작은 바꾸지 않는다.
