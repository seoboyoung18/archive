# H1 시안 보완·앉기/하단 검수 범위

전제: 전투 v0.3, 41포즈, ImageGen 및 비율 유지 정렬은 승인된 기준이다. 사용자 요청에 따라 다음 제작 단계를 진행한다.

## 범위와 순서
1. v1 원화·정렬 결과는 보존한다. 대기 원화를 기준으로 약손3포즈의 접지·가드 팔 일관성을 보완한 v2 후보를 만든다.
2. 같은 외형·카메라·몸 배율로 앉기1장과 앉은 약발 준비/유효/회복3장을 만든다. 앉은 자세를 선 자세 키로 재확대하지 않는다.
3. 생성 결과의 실제 크기를 측정하고 512×512 투명 PNG, 가상 원점(256,448), 표시 배율0.625에 맞춘다. 픽셀 덧그리기·파츠 합성 없이 비율 유지와 배치만 수행한다.
4. 검수 화면에서 선 약손과 앉은 약발 선택, 자세별 포즈·타이밍·판정 표시를 제공한다.
5. 검사와 빌드·브라우저 확인 결과, 채택/보류 이유를 검수 기록·개발일지에 남긴다.

## 명세 대응
- 선 약손: 준비6F/유효3F/회복15F, 피격 x[-36,36] y[-220,0], 공격 x[36,104] y[-190,-100].
- 앉은 약발: 준비8F/유효4F/회복18F, 피격 x[-36,36] y[-120,0], 공격 x[36,124] y[-60,-10], 하단.
- 좌향은 기준점 중심 반전. 유효 포즈에서만 공격 사각형을 표시한다.
- 반복 사이30F 대기는 검수 화면 전용이다. 재생 중 동작/포즈를 바꾸면 정지하고 새 포즈를 표시한다.
- 게임 전투, 실제 피해·방어·AI·라운드는 이번 변경에 포함하지 않는다. 승인된 수치를 그림에 맞춰 바꾸지 않는다.

## 완료 조건
- 새 원화·프롬프트·변환값·해시를 보존. v1과 기준 이미지 불변.
- 출력 RGBA512×512, 투명 여백, 경계 잘림 없음, 몸 배율 유지와 지면 기준점 검사. 앉기에는 대기 정수리 높이64 검사를 적용하지 않는다.
- 후보의 얼굴/의상·몸 배율·접지·타격 부위를 시각 검수한다. 불일치가 남으면 시안/보류로 기록하고 자동검사 통과와 분리한다.
- 타입 검사·빌드 및 브라우저에서 동작 선택·포즈·반전·판정 표시를 확인한다.
- 총41포즈 중 이 단계의 고유 포즈는8개이며, 버전별 후보를 별도 포즈로 중복 집계하지 않는다.
