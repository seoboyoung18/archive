# H1 전투 명세 초안
상태: 전투 규칙 제안. 아래 규칙은 구현 전 확정한다.
목적: 한 캐릭터로 입력 → 행동 → 타격 → 승패를 검증한다.

## 확정된 실행 조건 · 2026-09-30
- PC 브라우저에서 키보드로 조작한다. 지원 브라우저·버전과 키 배치는 미정이다.
- 첫 버전은 플레이어 대 AI의 1인용 대전만 제공한다. 로컬 2인은 제외한다.
- 엔진·언어와 아래 전투 규칙, 애니메이션 방식은 아직 확정하지 않았다.

## 전투 동작 제안

첫 개발 단계는 H1 대 H1 AI로 전투 흐름을 검증하고, 이후 B1/R3와 캐릭터 선택을 적용하는 안을 제안한다. 최종 첫 버전의 선택 캐릭터 3명 요구는 유지한다.
경기장 1개, 좌우 이동·점프·약공격·강공격·방어·피격·쓰러짐, 체력바·제한 시간·승패·재시작을 범위 후보로 둔다.
사용자 선택 전까지 이 범위와 구현 순서는 제안이며, 세부 규칙·수치도 별도 확정한다.

| 동작 | 기대 행동 | 결정할 항목 |
|---|---|---|
| 대기 | 기본 자세 반복 | 프레임 수·반복 시간 |
| 이동 | 좌우 이동, 경기장 경계에서 정지 | 속도·캐릭터 간 충돌 |
| 점프 | 지면에서 이륙 후 착지 | 높이·공중 이동/공격 허용 |
| 약공격 | 빠른 주먹 공격 | 키·거리·피해량·준비/유효/회복 시간 |
| 강공격 | 준비가 긴 발차기 | 키·거리·피해량·준비/유효/회복 시간 |
| 방어 | 조건에 맞는 공격 차단 | 전용키/뒤 방향·피해 감소·경직 |
| 피격 | 피해 및 행동 제한 | 경직·밀려남·공격 중단 여부 |
| 쓰러짐 | 체력 소진 시 입력 종료 | 종료 연출·라운드 전환 |

## 공통 규칙 제안
- 단타 공격 1회는 동일 상대에게 최대 1회 피해를 준다.
- 공격·피격 범위는 이미지 전체 크기와 별도로 관리한다.
- 공격 준비/유효/회복 시간과 동작 이미지를 연결한다.
- 경기 종료 후 추가 피해를 적용하지 않는다.

## 해소해야 할 모호성
동시 방향키, 공격키 유지, 동시 행동키의 처리.
동시 타격·동시 KO, 제한시간 동률 처리.
탭 전환/포커스 상실 시 일시정지 및 입력 해제.
상대를 넘어갈 때 방향 전환 시점, 공격 중 방향 고정.
공중 피격, 방어 중 공격, 화면 경계에서 밀려남.

## 확정 후 검증할 완료 조건
범위 밖 피해 없음, 단타 중복 피해 없음, 금지 상태 전이 없음.
종료 후 입력 제한. 재시작 시 체력·위치·시간·입력·공격 이력 초기화.
현재 게임 코드가 없으므로 위 검증은 미수행.
