# H1 전투 명세 초안 v0.1

목적: H1으로 입력 → 행동 → 타격 → 승패 → 재시작의 전체 흐름을 검증한다.
상태: **1절은 확정, 2절 이후 세부 규칙·수치는 검토용 제안**이다. 엔진·언어는 미정이며 이 문서는 구현 승인이 아니다.

## 1. 확정 범위
- PC 브라우저, 키보드 조작, 플레이어 대 AI의 1인용. 로컬 2인 제외.
- H1 대 H1 AI부터 검증하고 B1/R3와 캐릭터 선택을 추가한다. 첫 버전 최종 목표는 선택 캐릭터 3명이다.
- 경기장 1개, 좌우 이동·점프·공격 2종·방어·피격·쓰러짐, 체력바·제한 시간·승패·재시작.
- 소수 포즈의 프레임 교체 애니메이션. 원본 이미지 보존. 공통 처리와 캐릭터 데이터 분리.

## 2. 실행·경기 흐름 제안
- 첫 검증 대상: Windows PC의 Chrome·Edge. 실제 OS·브라우저 버전은 검증 시 기록한다. 모바일·터치·게임패드는 이번 검증 범위 밖이다.
- 논리 화면 1280×720, 종횡비 유지 확대/축소 및 여백 처리. 창 크기가 전투 거리·속도에 영향을 주지 않는다.
- 조작 안내·시작 버튼 → 에셋 로딩 성공 → H1 대 H1 대전 → 결과 → 재시작 버튼 또는 R.
- 로딩 실패 시 시작을 막고 실패 안내·다시 시도 버튼을 제공한다. 미완성 동작을 기준 이미지로 조용히 대체하지 않는다.
- H1 색상은 유지하고 PLAYER/CPU 머리 위 표식과 체력바 이름으로 선수를 구분한다.
- 1라운드, 체력 각각 100, 제한 시간 60초. 한쪽만 체력 0이면 상대 승리, 동시 KO는 무승부. 시간 종료 시 남은 체력이 높은 쪽 승리, 동률은 무승부.
- 종료 순간 입력·AI·피해·이동·경기 시간을 정지한다. KO 쓰러짐 애니메이션만 끝까지 재생한다. 결과와 재시작은 즉시 사용 가능하다.
- 포커스 상실·탭 숨김·Esc로 일시정지한다. 일시정지 중 모든 논리·그림 시간이 멈춘다. 복귀만으로 자동 재개하지 않고 계속 버튼·Enter·Esc로 재개한다.

## 3. 입력 제안
| 키 | 행동 |
|---|---|
| A / D | 왼쪽 / 오른쪽 이동, 유지 가능 |
| W | 점프, 누른 순간 1회 |
| J / K | 약공격 / 강공격, 누른 순간 1회 |
| L | 지상에서 유지하는 동안 방어 |
| Esc | 경기 중 일시정지/재개 |
| R | 결과 화면에서 같은 대전 재시작 |

- 물리 키 위치 기준. OS 키 반복으로 공격·점프를 재실행하지 않는다. A+D는 이동 0이다.
- 행동 가능한 지상의 동시 입력 우선순위: L 방어 > K 강공격 > J 약공격 > W 점프 > 이동.
- 공격·피격·방어 경직 중 공격·점프 입력은 버린다. 입력 예약·공격 취소·콤보는 제공하지 않는다.
- 방어 유지 중 공격·점프는 버린다. 방어를 해제하고 다시 눌러야 실행한다.
- 포커스 상실·일시정지·종료·재시작에서 입력 기록을 비운다. 재개 후 계속 눌려 있던 키는 놓았다가 새로 눌러야 한다. 재개 키 자체가 전투 입력이 되지 않는다.
- 활성 게임 영역에서 사용하는 키만 기본 브라우저 동작을 막는다. 시작·재개·재시작 버튼은 키보드로도 실행할 수 있다.

## 4. 좌표·시간·이동 제안
| 항목 | 값 |
|---|---|
| 논리 시간 | 초당 60회 고정 갱신. 1F는 논리 갱신 1회이며 그림 포즈 수와 별개 |
| 좌표 | 오른쪽 +x, 아래쪽 +y. 발 기준점이 선수 위치 |
| 지면·경계 | y=600, 선수 중심 x=80~1200 |
| 시작 위치 | PLAYER (400,600), CPU (880,600), 서로 마주봄 |
| 이동 | 초당 240 논리 픽셀 |
| 점프 | 초기 수직 속도 -800, 중력 +2000 픽셀/초² |
| 최소 선수 간 수평 거리 | 72 픽셀, 공중에서도 통과 불가 |

- 점프 중 좌우 이동 허용, 이중 점프·공중 공격·공중 방어 제외. 중력은 일정 가속도로 위치·속도에 함께 적분한다. 착지 시 y=600, 수직 속도 0으로 보정한다.
- 공격·방어 중 수평 이동 0. 피격 중 입력 이동 0, 공중 중력은 유지한다.
- 두 선수 이동을 동시에 계산한다. 간격 72 미만이면 겹침의 절반씩 분리한다. 경계에 막힌 분리량은 반대 선수에게 적용하여 경계·최소 간격을 모두 지킨다.
- 행동 가능한 지상 상태에서는 상대를 향한다. 공격·공중·피격 중에는 시작 방향을 유지한다. 상대 통과를 막으므로 뒤잡기는 제외한다.
- 한 갱신 순서: 입력 → 이동·접촉 해결 → 공격·방어 판정 스냅샷 → 양쪽 피해 동시 적용 → 경직·밀려남 → KO·시간 판정.
- 마지막 남은 1F의 타격까지 적용 후 시간 종료를 판단한다. KO가 시간 종료보다 우선한다.
- 지연 시 고정 단위로 누적 처리하되 렌더 갱신당 최대 5F 처리 후 과도한 나머지 지연을 버린다. 경기 시계는 실제 처리한 논리 시간만 사용하므로 과부하 시 벽시계와 다를 수 있다.

## 5. 공격·방어·피격 제안
모든 수치는 최초 조정 기준이다. 플레이 후 변경할 때 명세와 캐릭터 데이터를 함께 수정한다.

| 항목 | 약공격 J | 강공격 K |
|---|---|---|
| 동작 | 주먹 | 발차기 |
| 준비 / 유효 / 회복 | 6F / 3F / 15F | 12F / 4F / 24F |
| 전체 길이 | 24F = 0.4초 | 40F ≈ 0.667초 |
| 피해 | 8 | 14 |
| 피격 / 방어 경직 | 16F / 8F | 24F / 12F |
| 밀려남 / 방어 시 | 24 / 8 픽셀 | 48 / 16 픽셀 |
| 오른쪽 공격 사각형 | x=[36,104], y=[-190,-100] | x=[36,144], y=[-155,-65] |

- 판정은 발 기준점 상대 좌표. 왼쪽 방향은 x=[a,b]를 [-b,-a]로 반전한다.
- 피격 사각형은 x=[-36,36], y=[-220,0]. 공중·공격·피격 중에도 같은 형태로 선수 기준점을 따른다. 이미지 여백·팔다리 끝·꼬리를 자동 포함하지 않는다.
- 가로·세로 겹침이 각각 양수일 때만 타격이다. 경계선만 닿으면 미타격이다.
- 공격 시작 갱신의 나이는 0. 약공격은 [0,6) 준비, [6,9) 유효, [9,24) 회복. 강공격은 [0,12), [12,16), [16,40). 전체 길이에 도달한 다음 행동 가능 상태가 된다.
- 공격마다 식별자와 타격 상대 이력을 둔다. 동일 상대에는 공격 1회당 최대 1회 타격하며 방어도 이력에 포함한다. 준비·회복 중 공격 판정은 없다.
- 지상 방어·방어 경직 중 정면 공격은 피해 0으로 차단한다. 방어 중 이동·공격·점프 불가. 방어 경직은 L을 놓아도 만료까지 유지된다.
- 피격 시 진행 중 공격은 취소한다. 같은 갱신에 양쪽 유효 공격이 맞으면 취소 이전의 스냅샷에 따라 양쪽 피해를 모두 적용한다.
- 피격 중 재타격은 가능하고 경직은 새 값으로 교체한다. 무적 시간은 없다. 경직 N F는 피격 처리 이후 N회의 갱신 동안 입력 행동을 막는다.
- 밀려남은 공격자 반대 방향으로 즉시 적용하되 경기장 경계에서 제한한다. 공중 피격 시 수직 속도는 유지한다.
- 체력은 0~100. 체력 0이면 쓰러짐이 다른 상태보다 우선한다. 공중 KO는 경기 종료 위치를 고정하고 쓰러짐 그림만 지면에 정렬한다. 이 연출은 전투 판정을 재개하지 않는다.

## 6. 상태 전이 제안
| 상태 | 종료 및 전이 |
|---|---|
| 대기·이동 | 이동·점프·공격·방어, 피격/쓰러짐 |
| 점프 | 착지 시 대기·이동·방어, 공중 피격/쓰러짐 |
| 공격 준비·유효·회복 | 회복 완료 후 대기·이동·방어, 피격 시 공격 취소/쓰러짐 |
| 방어 | L 해제 시 대기·이동, 정면 타격 시 방어 경직 |
| 방어 경직 | 만료 후 L 유지 시 방어, 해제 시 대기·이동 |
| 피격 | 만료 시 공중이면 점프, 지상이면 대기·이동·방어. 체력 0이면 쓰러짐 |
| 쓰러짐 | 최종 포즈 유지, 재시작으로만 해제 |

경기 상태는 로딩·준비·진행·일시정지·종료·로딩 실패다. 일시정지는 선수 상태를 보존한다. 시간 종료 선수와 KO 승리 선수는 종료 순간 포즈를 유지한다.

## 7. 간단한 AI 제안
- PLAYER와 동일한 H1 데이터·행동 제약을 사용한다. AI는 공통 입력 명령을 만들며 직접 피해를 적용하지 않는다.
- 12F마다 위치·지상 여부·보이는 공격 상태를 읽는다. 사용자의 미공개 키 입력을 읽지 않는다.
- 행동 불가 상태에는 공격 펄스를 내지 않는다. 공격 도중에는 완료/피격까지 기다린다.
- 판단 우선순위: 지상 상대가 공격 준비/유효 중이고 중심 거리 180 이하이면 방어 → 상대가 공중이면 거리 160까지 접근 후 대기 → 지상 상대와 거리 132 이하이면 약공격 → 172 이하이면 강공격 → 나머지는 접근.
- 공격은 판단 순간 1회 펄스, 이동·방어는 다음 판단까지 유지하는 명령이다. AI는 이 단계에서 점프하지 않는다. 난이도 선택·학습·무작위 행동은 제외한다.
- 지상에서 약공격은 중심 거리 140 미만, 강공격은 180 미만에서 가로 판정이 겹친다. 132/172는 그 경계보다 8픽셀 안쪽의 값이다. AI의 재미·난이도는 플레이 검증 전이다.

## 8. 재시작 제안
페이지 새로고침 없이 체력·위치·방향·속도·경기 시간·결과·선수 상태·입력·공격 ID/타격 이력·경직·애니메이션·AI 판단 시간·누적 논리 시간을 초기화한다.
R을 유지해도 재시작은 한 번만 실행한다. 결과 화면의 입력을 새 경기로 전달하지 않는다.

## 9. 명세 기반 완료 조건
아래는 계획된 검증 항목이며 **현재 미수행**이다.

| ID | 상황 | 기대 결과 |
|---|---|---|
| V01 | A+D, J 유지, J+K, L+J | 이동 0, 공격 1회, 강공격만, 방어만 |
| V02 | 공격/피격 중 공격 후 해제 | 행동 가능 시 예약 공격 없음 |
| V03 | 공중 W/J/L, 경계 이동 | 이중 점프·공중 공격·방어 없음, 경계 이탈 없음 |
| V04 | 공격 유효 직전/첫 F/마지막 F/직후 | 유효 구간에서만 피해 |
| V05 | 한 공격에 여러 F 접촉 | 피해/방어 1회 |
| V06 | 경계 접촉, 1픽셀 겹침, 좌우 반전 | 미타격, 타격, 대칭 결과 |
| V07 | 방어와 방어 경직 중 타격 | 체력 유지, 지정 경직·밀려남 |
| V08 | 공격 중 피격, 동시 유효 타격 | 공격 취소, 동시 타격은 양쪽 피해 |
| V09 | 동시 KO, 시간 동률, 마지막 F KO | 무승부, 무승부, KO 우선 |
| V10 | 종료 후 입력·공격 잔류 | 체력·위치·결과 불변 |
| V11 | 경계 밀려남·선수 접촉 | 경계와 최소 간격 유지 |
| V12 | 공격 중 탭 이탈·복귀 | 논리 정지, 명시적 재개, 키 잔류 없음 |
| V13 | 재시작 3회 | 8절의 상태가 매번 첫 시작과 동일 |
| V14 | 창 크기·표시 주사율 변경 | 같은 논리 입력 기록의 결과 동일 |
| V15 | 이미지 누락·잘못된 공격 구간 | 시작 차단·안내·재시도 가능 |
| V16 | PLAYER/CPU의 같은 공격 | 피해·거리·타이밍 규칙 동일 |
| V17 | 시작→전투→결과→재시작 | 키보드/버튼으로 완주, 오류 로그 확인 |

수치·상태는 자동 검증하고 키보드·탭 전환·이미지 정렬은 실제 브라우저에서 확인한다. 체감 타격감·공정성은 플레이 후 별도 기록한다.
