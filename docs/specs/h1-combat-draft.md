# H1 전투 명세 v0.3 · 초기 구현 기준

목적: H1으로 입력 → 행동 → 타격 → 승패 → 재시작의 전체 흐름을 검증한다.
후속 변경 요청(2026-10-01): 정해진2~3타 콤보·U+I 잡기와 타격 효과음은 [확장 초안](h1-combat-expansion.md)에서 검토 중이다. 아래 v0.3은 현재 구현 기준이며 공격 중 입력 폐기 등 변경 예정 규칙은 상세 승인 후 함께 갱신한다.
상태: **2026-09-30 사용자가 v0.3 상세안을 초기 구현 기준으로 확정했다.** 전투 수치·입력·상태·경기·AI 규칙을 구현 기준으로 사용한다. 실제 동작과 밸런스는 구현 후 검증하며 변경 시 명세와 데이터를 함께 갱신한다. 기술 구성은 Phaser 4 + TypeScript + Vite로 확정했다. 파일명은 기존 링크 보존을 위해 유지한다.

2026-10-02 경기 표시·수동 전환·KO 연출 대기와 초기화의 구체 기준은 승인된 [경기 진행 v0.2](h1-match-flow.md)를 따른다. 표적 경기 화면을 먼저 연결하며 AI의 강발 선택과 전투 확장 미정안은 별도다.

## 1. 확정 범위
- PC 브라우저, 키보드 조작, 플레이어 대 AI의 1인용. 로컬 2인 제외.
- H1 대 H1 AI부터 검증하고 B1/R3와 캐릭터 선택을 추가한다. 첫 버전 최종 목표는 선택 캐릭터 3명이다.
- 경기장 1개, WASD 방향 조작·점프·약손·강손·약발·강발 공격·뒤 방향 방어·피격·쓰러짐, 체력바·제한 시간·승패·재시작.
- W 점프·S 앉기·A/D 좌우. 앞/뒤는 상대 방향 기준이며 뒤로 선 방어, S+뒤로 앉은 방어를 한다. 전용 방어키는 없다.
- 3판 2승제로 먼저 2라운드를 이기면 경기 승리다. 시간 초과 시 체력이 적은 쪽이 해당 라운드에서 패배한다.
- U 약손·I 강손·J 약발·K 강발. 선 자세 4개 + 앉은 자세 4개의 공격을 제공한다. 공중 공격은 이후로 미루고 공중 방어는 제외한다.
- 일반 공격은 선/앉은 방어 모두 가능, 중단은 선 방어만 가능, 하단은 앉은 방어만 가능하다. 공격별 분류는 아래 상세 기준과 구분한다.
- 시간 초과 동일 체력 또는 동시 KO는 승수 변화 없이 해당 라운드를 재경기하며, 이 예외 때문에 실제 라운드 횟수가 3회를 넘을 수 있다.
- 소수 포즈의 프레임 교체 애니메이션. 원본 이미지 보존. 공통 처리와 캐릭터 데이터 분리.

## 2. 실행·경기 흐름
- 첫 검증 대상: Windows PC의 Chrome·Edge. 실제 OS·브라우저 버전은 검증 시 기록한다. 모바일·터치·게임패드는 이번 검증 범위 밖이다.
- 논리 화면 1280×720, 종횡비 유지 확대/축소 및 여백 처리. 창 크기가 전투 거리·속도에 영향을 주지 않는다.
- 조작 안내·시작 버튼 → 에셋 로딩 성공 → 라운드 준비 → 대전 → 라운드 결과 → 2승 전이면 다음 라운드, 2승 달성 시 경기 결과 → 재시작 버튼 또는 R.
- 로딩 실패 시 시작을 막고 실패 안내·다시 시도 버튼을 제공한다. 미완성 동작을 기준 이미지로 조용히 대체하지 않는다.
- H1 색상은 유지하고 PLAYER/CPU 머리 위 표식과 체력바 이름으로 선수를 구분한다.
- 확정: 3판 2승. 2:0이면 세 번째 라운드를 진행하지 않고, 1:1이면 세 번째 라운드 승자가 경기에서 승리한다.
- 확정: 라운드 시간 종료 시 체력이 적은 쪽 패배, 높은 쪽 승리. 시간 종료 자체를 무승부로 처리하지 않는다. 체력이 같은 경우·동시 KO는 승수 변화 없이 해당 라운드를 재경기한다. 예외적으로 실제 진행 횟수는 3회를 넘을 수 있다.
- 확정: 라운드마다 체력 각각 100, 제한 시간 60초. 한쪽만 체력 0이면 상대가 라운드 승리한다. 승수는 라운드당 한 번만 반영한다.
- 확정: 라운드 종료 순간 입력·AI·피해·이동·라운드 시간을 정지한다. KO 쓰러짐 그림만 끝까지 재생한다. 라운드 결과에 승수와 다음 라운드 버튼을, 경기 결과에 재시작 버튼을 표시한다.
- 확정: 다음 라운드는 사용자가 버튼 또는 Enter로 시작한다. 체력·위치·타이머는 초기화하고 경기 승수는 유지한다. 라운드 번호와 각 선수의 승수 표시를 둔다.
- 포커스 상실·탭 숨김·Esc로 일시정지한다. 일시정지 중 모든 논리·그림 시간이 멈춘다. 복귀만으로 자동 재개하지 않고 계속 버튼·Enter·Esc로 재개한다.

## 3. 방향·공격 입력
### 확정된 방향 조작
| 키 | 행동 |
|---|---|
| W | 점프 |
| A / D | 화면 왼쪽 / 오른쪽. 상대가 오른쪽이면 D 전진·A 후진, 상대가 왼쪽이면 A 전진·D 후진 |
| S | 앉기, S+뒤는 앉은 방어 |
| 뒤 방향 | 방어 입력을 겸한다. 별도 방어 버튼 없음 |

### 확정된 공격키 배치
| 키 | 공격 슬롯 | 상태 |
|---|---|---|
| U / I | 약손 / 강손 | 확정. 현재 선/앉은 자세에 따라 공격 선택 |
| J / K | 약발 / 강발 | 확정. 현재 선/앉은 자세에 따라 공격 선택 |

윗줄은 손, 아랫줄은 발로 묶는다. 기존 J 약공격/K 강공격과 전용 L 방어 매핑은 폐기한다.

### 아래 방향·후진·동시 입력 세부
- 확정: S 유지로 앉기, S+뒤로 앉은 방어. S만 또는 S+앞으로는 방어하지 않는다. 확정: 앉은 동안 이동은 0이다.
- 뒤 방향을 유지하면 평상시 후진하고, 방어 가능한 공격이 접촉한 갱신에 방어 판정을 한다. 상대가 공격하지 않을 때부터 제자리에 멈춰 방어 자세만 유지하지 않는다.
- 뒤 방향은 단순 화면 왼쪽이 아니라 상대 반대쪽이다. 방향 해석을 PLAYER/CPU에 똑같이 적용한다.
- 공격/점프를 시작하면 그 행동 동안 후진 방어 자격을 잃는다. 따라서 뒤 방향을 누른 채 공격해도 공격 동작이 나오며 동시에 방어하지 않는다. 방어 경직 중에는 공격·점프를 시작할 수 없다.
- A+D는 중립으로 보아 이동·뒤 방향 방어 없음. W+S는 수직 중립으로 처리한다.
- 일반 지상 상태의 입력 순서 확정: 방향 상쇄 → 현재 S로 자세 결정 → 해당 자세의 공격 1회 입력 → 점프 1회 입력 → 전진/후진/대기. S+공격을 같은 갱신에 누르면 앉은 공격을 선택한다. 공격 여러 개는 강발 > 강손 > 약발 > 약손 중 하나만 실행한다. 합성 기술은 추가하지 않는다.
- 공격 시작 시 자세·방향을 고정한다. 공격 중 S를 누르거나 놓아도 공격 종류·피격 범위는 바뀌지 않는다. 회복 후 현재 입력의 자세로 돌아간다. 점프 중 공격 입력은 버리고 착지 후 예약 실행하지 않는다.
- 물리 키 위치 기준. OS 키 반복으로 공격·점프를 재실행하지 않는다. 공격·피격·방어 경직 중 입력은 예약하지 않고 버린다.
- Esc 일시정지/재개, 경기 결과에서 R 재시작을 적용한다. 라운드 결과의 다음 라운드와 경기 전체 재시작은 구분한다.
- 포커스 상실·일시정지·라운드 전환·종료·재시작에서 입력 기록을 비운다. 계속 눌렸던 키는 놓았다가 새로 눌러야 한다. UI 입력이 전투 입력이 되지 않는다.
- 활성 게임 영역에서 사용하는 키만 기본 브라우저 동작을 막는다. 시작·다음 라운드·재개·재시작 버튼은 키보드로도 실행할 수 있다.

## 4. 좌표·시간·이동
앉기·방어 표의 확정 내용과 자세 전이·피격 범위 기준은 [앉기·방어 상세안](h1-guard-review.md)에 기록한다.

| 항목 | 값 |
|---|---|
| 논리 시간 | 초당 60회 고정 갱신. 1F는 논리 갱신 1회이며 그림 포즈 수와 별개 |
| 좌표 | 오른쪽 +x, 아래쪽 +y. 발 기준점이 선수 위치 |
| 지면·경계 | y=600, 선수 중심 x=80~1200 |
| 시작 위치 | PLAYER (400,600), CPU (880,600), 서로 마주봄 |
| 이동 | 초당 240 논리 픽셀 |
| 점프 | 초기 수직 속도 -800, 중력 +2000 픽셀/초² |
| 최소 선수 간 수평 거리 | 72 픽셀, 공중에서도 통과 불가 |

- 공중 공격·공중 방어 제외는 확정이다. 확정: 점프 중 좌우 이동 허용, 이중 점프 제외. 중력은 일정 가속도로 위치·속도에 함께 적분한다. 착지 시 y=600, 수직 속도 0으로 보정하고 현재 S에 따른 선/앉은 자세로 돌아간다.
- 공격·방어 경직·앉기 중 수평 이동 0. 뒤 방향 유지 중 경직이 없으면 후진한다. 피격 중 입력 이동 0, 공중 중력은 유지한다.
- 두 선수 이동을 동시에 계산한다. 간격 72 미만이면 겹침의 절반씩 분리한다. 경계에 막힌 분리량은 반대 선수에게 적용하여 경계·최소 간격을 모두 지킨다.
- 행동 가능한 지상 상태에서는 상대를 향한다. 공격·공중·피격 중에는 시작 방향을 유지한다. 상대 통과를 막으므로 뒤잡기는 제외한다.
- 한 갱신 순서: 입력 → 이동·접촉 해결 → 공격·방어 판정 스냅샷 → 양쪽 피해 동시 적용 → 경직·밀려남 → KO·시간 판정.
- 마지막 남은 1F의 타격까지 적용 후 시간 종료를 판단한다. KO가 시간 종료보다 우선한다.
- 지연 시 고정 단위로 누적 처리하되 렌더 갱신당 최대 5F 처리 후 과도한 나머지 지연을 버린다. 경기 시계는 실제 처리한 논리 시간만 사용하므로 과부하 시 벽시계와 다를 수 있다.

## 5. 공격·방어·피격
모든 수치는 최초 조정 기준이다. 플레이 후 변경할 때 명세와 캐릭터 데이터를 함께 수정한다.

| 항목 | 약손 | 강손 | 약발 | 강발 |
|---|---|---|---|---|
| 입력키(확정) | U | I | J | K |
| 선 자세 방어 종류 | 일반 | 일반 | 일반 | 중단 |
| 동작 | 빠른 주먹 | 힘을 실은 주먹 | 짧은 발차기 | 뒤쪽 다리를 높게 뻗는 발차기 |
| 준비/유효/회복 | 6F/3F/15F | 10F/3F/21F | 8F/4F/18F | 12F/4F/36F |
| 총 길이 | 24F | 34F | 30F | 52F |
| 피해 | 8 | 12 | 10 | 16 |
| 피격/방어 경직 | 16F/8F | 20F/10F | 18F/10F | 24F/12F |
| 밀려남/방어 시 | 24/8 | 36/12 | 32/10 | 48/16 |
| 오른쪽 공격 x 구간 | [36,104] | [36,124] | [36,134] | [100,125] |
| 공격 y 구간 | [-190,-100] | [-190,-100] | [-155,-65] | [-230,-200] |

선 강발은 2026-10-02 사용자 검수 요청에 따라 [첫 발차기 타격 기준](h1-heavy-kick-contact.md)으로 변경했다. 준비24F/회복24F였던 이전 기준을 준비12F/회복36F로 대체해 첫 발 뻗기12~15F에 타격하며 총52F·유효4F·피해16을 유지한다. 반응 시간과 회복의 밸런스는 후속 플레이에서 검증한다.

후속 요청으로 선 강발 판정을 완전히 뻗은 신발 앞부분에 맞췄다. 발 아래의 기존 판정은 제거하며 선 상대 접촉 경계는190에서161로 줄어든다. 같은 지면의 앉은 피격 범위에는 닿지 않아 헛친다. `중단`은 접촉 시의 방어 분류로 유지하며 사각형 비접촉이 우선한다.

### 앉은 공격
| 항목 | 앉은 약손 | 앉은 강손 | 앉은 약발 | 앉은 강발 |
|---|---|---|---|---|
| 입력키(확정) | S+U | S+I | S+J | S+K |
| 방어 종류 | 일반 | 일반 | 하단 | 하단 |
| 준비/유효/회복 | 6F/3F/15F | 10F/3F/21F | 8F/4F/18F | 14F/4F/24F |
| 총 길이 | 24F | 34F | 30F | 42F |
| 피해 | 6 | 10 | 8 | 14 |
| 피격/방어 경직 | 16F/8F | 20F/10F | 18F/10F | 24F/12F |
| 밀려남/방어 시 | 24/8 | 36/12 | 32/10 | 48/16 |
| 오른쪽 공격 x 구간 | [36,96] | [36,112] | [36,124] | [36,144] |
| 공격 y 구간 | [-115,-65] | [-115,-65] | [-60,-10] | [-60,-10] |

같은 4개 키를 자세별로 사용한다. 공격 도중 선/앉은 자세를 바꿔 다른 공격으로 변환하지 않는다. 앉은 손은 낮은 몸통 주먹, 앉은 발은 발목 쪽 발차기를 적용하며 피격 위치와 그림을 함께 검수한다.

- 판정은 발 기준점 상대 좌표. 왼쪽 방향은 x=[a,b]를 [-b,-a]로 반전한다.
- 피격 사각형 확정: 선 자세 x=[-36,36], y=[-220,0], 앉은 자세 x=[-36,36], y=[-120,0]. 공중은 선 범위, 공격 중은 시작 자세 범위, 피격 중은 맞을 때의 자세 범위를 경직 만료까지 유지한다. 이미지 여백·팔다리 끝·꼬리를 자동 포함하지 않는다.
- 가로·세로 겹침이 각각 양수일 때만 타격이다. 경계선만 닿으면 미타격이다.
- 공격 시작 갱신의 나이는 0. 각 공격의 준비 P, 유효 A, 회복 R에 대해 [0,P), [P,P+A), [P+A,P+A+R)로 나눈다. 합계에 도달한 다음 행동 가능 상태가 된다. P/A/R은 위 표의 초기 기준값을 사용한다.
- 공격마다 식별자와 타격 상대 이력을 둔다. 동일 상대에는 공격 1회당 최대 1회 타격하며 방어도 이력에 포함한다. 준비·회복 중 공격 판정은 없다.
- 확정 방어 표: 일반은 선/앉은 방어 모두, 중단은 선 방어만, 하단은 앉은 방어만 가능하다. 먼저 판정 사각형이 접촉해야 하며 뒤 입력 없이 자동으로 막지 않는다. 방어 시 피해 0은 초기 기준이다.
- 방어 경직 중 이동·공격·점프 불가. 뒤 방향을 놓아도 경직은 만료까지 유지한다. 후속 타격을 다시 방어하려면 타격 판정 시 뒤 방향 및 자세 조건을 만족해야 한다. 입력 없이 자동 방어하는 상태로 만들지 않는다.
- 확정: 방어 경직 중에는 S 입력으로 선/앉은 자세를 전환할 수 있다. 후속 방어 성공 시 경직은 새 값으로 교체한다. 피격 경직에서는 자세 전환을 허용하지 않는다.
- 피격 시 진행 중 공격은 취소한다. 같은 갱신에 양쪽 유효 공격이 맞으면 취소 이전의 스냅샷에 따라 양쪽 피해를 모두 적용한다.
- 피격 중 재타격은 가능하고 경직은 새 값으로 교체한다. 무적 시간은 없다. 경직 N F는 피격 처리 이후 N회의 갱신 동안 입력 행동을 막는다.
- 밀려남은 공격자 반대 방향으로 즉시 적용하되 경기장 경계에서 제한한다. 공중 피격 시 수직 속도는 유지한다.
- 체력은 0~100. 체력 0이면 쓰러짐이 다른 상태보다 우선한다. 공중 KO는 경기 종료 위치를 고정하고 쓰러짐 그림만 지면에 정렬한다. 이 연출은 전투 판정을 재개하지 않는다.

## 6. 상태 전이
| 상태 | 종료 및 전이 |
|---|---|
| 대기·전진·후진 | 이동·점프·공격·앉기, 뒤 입력 조건 충족 시 방어 경직, 그 외 피격/쓰러짐 |
| 앉기 | S 해제 시 선 상태, 앉은 공격 4종 가능. S+뒤는 일반/하단 방어, 중단 피격 |
| 점프 | 착지 시 유지 방향에 따른 지상 상태, 공중 피격/쓰러짐 |
| 공격 준비·유효·회복 | 시작 자세 고정, 회복 완료 후 유지 방향에 따른 지상 상태, 피격 시 공격 취소/쓰러짐 |
| 방어 경직 | 만료 후 유지 방향에 따른 지상 상태. 후속 타격은 현재 뒤 입력·자세로 다시 판정 |
| 피격 | 만료 시 공중이면 점프, 지상이면 유지 방향에 따른 지상 상태. 체력 0이면 쓰러짐 |
| 쓰러짐 | 라운드 결과까지 최종 포즈 유지, 다음 라운드 또는 경기 재시작으로 해제 |

경기 상태는 로딩·라운드 준비·라운드 진행·일시정지·라운드 결과·경기 결과·로딩 실패다. 일시정지는 선수 상태를 보존한다. 시간 종료 선수와 KO 승리 선수는 종료 순간 포즈를 유지한다. 승수가 2가 되면 경기 결과로 이동하고 다음 라운드를 생성하지 않는다. 동률·동시 KO는 승수를 그대로 유지한 채 해당 라운드 준비로 돌아간다.

## 7. 간단한 AI
2026-10-02 후속 [AI 대전 v0.1 검토안](h1-ai-match.md): 아래의 공통 입력·12F 판단·동일 행동 제약을 유지하면서 공격 선택을 순환 방식으로 보완하고 관찰·정지·초기화 규칙을 구체화했다. 새 공격 순서와 화면 연결은 **승인 대기**이며 아래 과거 거리 우선 규칙을 아직 승인된 새 규칙처럼 바꾸지 않는다. 실제 AI는 미구현이다.

- PLAYER와 동일한 H1 데이터·행동 제약을 사용한다. AI는 공통 입력 명령을 만들며 직접 피해를 적용하지 않는다.
- 12F마다 위치·지상 여부·보이는 공격 상태를 읽는다. 사용자의 미공개 키 입력을 읽지 않는다.
- 행동 불가 상태에는 공격 펄스를 내지 않는다. 공격 도중에는 완료/피격까지 기다린다.
- 방어가 필요하면 전용 방어 명령 대신 상대 반대쪽 방향을 입력한다. 앉은 방어는 아래+뒤 입력을 사용한다. 사용자와 동일한 공통 판정을 거친다.
- 공격은 약손·강손·약발·강발 중 하나의 1회 펄스다. 초기 기준은 중심 거리132 이하 약손, 그 초과~152 강손, 그 초과~162 약발이다. 선 강발의 이전162 초과~182 선택 구간은 발끝 보정으로 폐기한다. 강발의 새 접촉 경계161에서8픽셀 여유를 두면153이므로 다른 공격과의 선택 우선순위는 AI 구현 전에 재검토해야 한다. AI는 아직 미구현이다.
- 방어 확정: 12F 판단 시 상대의 현재 공개된 공격이 준비/유효 중이고 닿을 수 있는 거리면 공격 선택보다 방어를 우선한다. 중단에는 선 뒤, 하단에는 아래+뒤, 일반에는 현재 선/앉은 자세+뒤를 유지한다. 판단 사이에는 입력을 유지해 즉시 자동 대응하지 않는다.
- 공격 선택 보완: 상대가 선 방어 중이면 앉은 발 공격을 시도한다. 중심 거리152 이하 앉은 약발,172 이하 앉은 강발, 그 밖에는 접근한다. 기존 앉은 방어 상대에게 선 강발을 시도하는 기준은 발끝 판정이 닿지 않으므로 재검토 대상이다. 새 방어 공략 행동을 이번 수정에서 임의로 추가하지 않는다.
- 공격 판단 시 이미 앉은 자세이고 위 방어 공략 조건이 없으면 거리 124/140/152/172를 차례대로 기준으로 앉은 약손/강손/약발/강발을 고른다. 범위 밖이면 아래를 해제하고 접근한다. 선 자세의 약손/강손/약발은 앞의132/152/162 기준이며 강발 선택은 후속 승인 대상이다. 폐기된182를 사용하지 않는다.
- 상대가 공중이면 중심 거리 160까지 접근 후 대기한다. AI는 이번 단계에서 점프하지 않는다. 이동·아래 입력은 다음 판단까지 유지한다. 난이도 선택·학습·무작위 행동은 현재 범위 밖이며 재미·난이도는 미검증이다.

## 8. 다음 라운드·재시작
- 다음 라운드: 체력·위치·방향·속도·남은 라운드 시간·라운드 결과·선수 상태·입력·공격 ID/타격 이력·경직·애니메이션·AI 판단 시간·누적 논리 시간을 초기화한다. 경기 승수는 유지하고 완료된 라운드 수를 반영한다.
- 경기 전체 재시작: 위 항목과 양쪽 승수·라운드 번호·경기 결과까지 초기화한다. 페이지를 새로고침하지 않는다.
- 다음 라운드/재시작 입력은 한 번만 처리하며 화면 전환 전 입력을 새 라운드에 전달하지 않는다. 타이머나 KO 이벤트가 중복되어도 승수는 한 번만 올라간다.
- 동률·동시 KO 재경기: 승수와 해당 라운드 번호는 유지하고 체력·시간·위치 등 전투 상태를 새 라운드와 동일하게 초기화한다. 예외 재경기는 3판의 승패 결정 라운드 수에 포함하지 않는다.

## 10. 연결 문서와 승인 범위
- [애니메이션 초안](h1-animation-draft.md): 그림 포즈와 전투 타이밍.
- [설계 초안](../design/h1-combat-design.md): 공통 처리·캐릭터 데이터·정합성 검토.
- 전투 상세안과 이미지 규격·41포즈 계획, Phaser 4 + TypeScript + Vite가 승인됐다. 실제 이미지의 외형·정렬·판정 일치는 시안에서 검증한다. 이 문서의 승인은 게임 전체 구현·플레이 검증 완료를 뜻하지 않는다.
