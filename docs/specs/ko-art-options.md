# KO 연출 시안과 모션 개선 요청 · 2026-10-01

## 사용자 요청과 이번 범위

- 확정: 모션이 아직 부드럽지 않다는 사용자 피드백. 현재 그림 연결을 완성 품질로 보지 않는다.
- 확정: 승리 때 화면에 정확한 문구 `K O!!`를 표시하는 연출을 원한다. 여러 이미지를 보고 사용자가 선택한다.
- 사용자 선택: **A — 빨강·금색 만화풍**. 세 원화를 보존하고 A를 전투 검수 화면에 연결한다.
- 표시 기준: 체력0으로 전투가 종료되면 중앙에 `K O!!`를 표시하고 초기화하면 숨긴다. 일시정지 중에도 종료 표시는 유지한다. 그림은 논리 화면 중앙 (640,270)에 가로640 크기로 비율을 유지해 표시한다. 승수·타이머가 없는 현재 검수 화면의 KO 표시이며 최종 경기 승리 연출은 후속이다.
- 시안 방향: A 빨강/금색의 굵은 만화풍 충격 글자, B 보라/민트 차원 균열, C 흰색/빨강 붓 터치. 같은 문구와 가로형 중앙 구도, 캐릭터·배경·다른 문구 없음.
- 2026-10-02 [경기 진행 v0.2](h1-match-flow.md) 승인: 경기 화면의 한쪽 KO는 A 이미지, 시간 종료는 `TIME UP`, 동시 KO는 `DOUBLE KO`를 표시한다. 최종2승은 `승리!`/`패배`와 점수를 추가한다. KO/동시 KO의 쓰러짐18F가 끝난 후 후속 전환을 허용하며 시간 종료는 즉시 허용한다. 기존 전투 전용 검수의 KO/초기화 동작은 보존한다.

## 모션 분석과 후속 보완안

현재60Hz 전투 갱신과 별개로 공격은 준비·유효·회복 각각1장, 총3포즈다. 예를 들어 선 강발은 준비24F와 회복24F를 각 한 그림으로0.4초 유지한다. 그 사이 관절이 이동하는 그림이 없고 지지발/상체 위치도 포즈마다 달라 끊김이 눈에 띈다.

제안: 발 위치·몸 비율부터 고정하고, 사용자가 지적한 동작에 중간 포즈를 추가해 비교한다. 준비/유효/회복의 전체 길이와 피해·판정은 유지하며 그 구간 내부에서만 여러 그림을 배분한다. 걷기는 발의 접지→체중 이동→반대발 접지 연결을 점검한다. 최종 포즈 수·구간별 그림 배분은 비교 시안과 함께 명세에 기록하고 품질을 확인한 뒤 확장한다.

현재41장은 최초 최소 시안 계획이며 부드러움의 완료 기준이 아니다. 이번 문서는 실제 모션 개선·전체 애니메이션 검증 완료를 주장하지 않는다.

## 검증과 보존

ImageGen 내장 도구로 개별 생성하고 원화·정확한 프롬프트·해시를 `assets/ui/ko/options-v1`에 보존한다. 실제 글자, 가독성, 배경 알파, 여백을 확인하고 사용자에게 A/B/C를 보여준다. 선택 페이지나 게임 기능은 시안 제작에 불필요하면 추가하지 않는다.
