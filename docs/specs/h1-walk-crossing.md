# H1 교차 보행 보완 · 2026-10-01

사용자 요청: 이미지를 더 제작하여 움직임을 부드럽게 하고, 걷기에서 앞발과 뒷발이 일반 보행처럼 번갈아 교차하도록 만든다. 기존 경기/콤보/잡기/효과음 초안 승인과 별개인 모션 보완 작업이다.

## 범위와 제작 기준

- 기존8장에 비슷한 자세를 더 끼우는 대신 완전한 좌우 다리 교대 주기의12포즈를 `walk-v2`에 새로 제작한다. 이전 원화/출력은 모두 보존한다.
- 화면은 계속 오른쪽을 보는 H1이다. 앞/뒤는 화면 위치이고, 가까운 다리/먼 다리는 고정된 신체 구분이다. 가까운 다리가 앞에 있는 반주기와 먼 다리가 앞에 있는 반주기를 각각 그린다. 몸 전체 좌우 반전으로 반주기를 만들지 않는다.
- 0 가까운 발 앞 접지 →1 체중 이동 →2 먼 발 회수 →3 먼 발이 지지발 옆을 지남 →4 먼 발 앞으로 →5 먼 발 접지 직전 →6 먼 발 앞 접지 →7 체중 이동 →8 가까운 발 회수 →9 가까운 발 통과 →10 가까운 발 앞으로 →11 가까운 발 접지 직전 →0.
- 두 발이 동시에 공중에 뜨지 않는다. 지지발은 바닥에 닿고 회수하는 발은 들어 올린다. 발끝은 진행 방향을 향하며 다리가 좌우로 벌어지는 옆걸음이나 같은 다리만 앞에 남는 셔플을 피한다.
- 얼굴·검은 단발·빨간 재킷·흰 운동복·검은 바지/빨간 줄·붕대·빨간 운동화·몸 비율·가드 자세를 유지한다. 작은 체중 이동은 허용하지만 머리 크기·카메라·그림 배율은 바뀌지 않는다.
- 개별 투명 PNG, 같은 원화 캔버스1254×1254, 머리 상단 약74, 바닥1194, 몸 중심627 기준으로 제작한다. 출력512×512, 발 기준점(256,448), 기존 공통 배율384/1120·표시0.625를 유지한다. 그림마다 높이를 다시 맞춰 늘리지 않는다.
- 내장 ImageGen으로 생성하고 정확한 프롬프트·원화·해시·정렬값을 보존한다. 스크립트는 승인된 비율 유지 축소와 투명 배치만 한다.

## 재생과 적용

- 이동240·점프·피해·공격 시간은 변경하지 않는다.12포즈는 순서대로 재생하고 정지/피격/공격/KO에서 해당 상태로 전환한다.
- 사용자 선택으로 재생 주기는48F(0.8초, 각4F)로 확정했다. 기존24F보다 한 주기를 길게 보여주되 이동 속도와 공격 시간은 유지한다.
- 전투 검수에 새 보행을 연결하고 비교 화면에는 이전8포즈와 새12포즈를 명확히 구분해 제공한다. 이전 이동 전용 검수는 보존한다.
- 후진 때도 다리가 교차하되 실제 진행 방향과 지지발 이동이 맞도록 보행 순서를 역재생한다. 정면을 보는 방향은 기존 상대 바라보기 규칙을 따른다.

## 검증 계획

12장의 접지/다리 교대/교차 순서와 원본 불변을 확인한다. 정렬·RGBA·여백·해시 검증, 포즈 선택 주기·반대 방향 이동·정지/상태 전환 회귀, 타입 검사·빌드, 비교 화면 및 전투 브라우저 검수. 보행 그림의 신체 좌우 구분과 실루엣을 실제로 보고 판단하며 파일 수만으로 자연스러움이 통과했다고 보고하지 않는다. 부적합 그림은 별도 후보로 재생성하고 탈락 후보도 보존한다.
