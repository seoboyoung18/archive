# H1 전투 판정 검증

2026-10-01. [단계 명세](../specs/h1-combat-core.md)에 따른 순수 TypeScript 로직 구현 결과. **공격·방어·피격 계산 완료, 브라우저 대전 연결 전**이다.

## 구현

- 선/앉은 공격8종을 H1 정의에 분리했다. 새 캐릭터가 같은 행동 규칙을 쓰면 정의를 전달해 공통 전투 함수를 사용할 수 있다. 테스트용 다른 정의로 서로 다른 체력/피해를 적용해 코드 복제 없이 작동하는지 확인했다. B1/R3의 실제 수치는 확정하지 않았다.
- 실제 생성된 공격별 ID·나이·상대ID 이력으로 단타 중복을 막는다. 그림 구간 조회와 타격 유효 여부는 같은 나이를 쓴다.
- 두 선수 접촉 계산 뒤 타격을 함께 수집하고 피해·경직·밀려남을 적용한다. KO는 그 다음 결정하며 종료 후 상태를 고정한다.
- 입력은 물리 키 코드와 새 누름을 사용한다. 공격 여러 개는 강발>강손>약발>약손으로 선택한다. 행동 불가 중 소비된 펄스는 예약하지 않는다.
