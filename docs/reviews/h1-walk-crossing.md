# H1 교차 보행 검수 · 2026-10-01

## 적용 결과
사용자 요청으로 기존8장 대신 새12장을 제작했다. 사용자가 승인한 한 주기48F(0.8초), 각4F로 전투 화면에 연결했다. 런타임 고유 포즈는52개이며 이전 원화·출력은 보존했다. 이동240, 점프, 공격8종의 시간/피해, 약손6포즈, KO A는 유지한다. 후진에는 새 보행을 역순으로 재생한다.

## 이미지 검수
- 내장 ImageGen 원화19장(최초12+재생성7), 선택 출력12장. 정확한 프롬프트는 generated/walk-v2의4개 JSON에 저장했다.
- 00의 빨간 줄 다리가 앞,06에서는 뒤로 가며03/09는 두 다리가 겹쳐 지나간다. 양발이 번갈아 지지하고 회수하는 단계가 이전보다 구분된다.
- 03은 회수발이 계속 뒤에 남아 재생성했다.06/07/08은 빨간 줄 다리가 계속 앞에 남는 오류를 교정했다.08/10의 높이 기준 초과도 재생성했다. 탈락 후보는 보존했다.
- 최종 선택:03/06/07/10의-v2,08의-v4, 나머지는 첫 결과. 공통384/1120배율·발 루트(256,448), 신체 재합성/개별 확대 없음. 출력 상단62~68, 하단447. 허용 검사 범위를 완화하지 않았다.
- 프롬프트 좌표는 목표이며 생성 이미지의 관절 좌표가 정확히 일치한다는 뜻은 아니다. 발 이동 간격이 완전히 균일하지 않아 미세한 미끄러짐은 남는다.

## 검증
- 자동60개 테스트 통과:12포즈×4F/48F 반복, 좌우 양쪽에서 전진/후진 포즈와 이동량, 기존 공격·방어·KO·입력·초기화 회귀 포함.
- 에셋 검사 통과:52개 런타임 경로,512×512 RGBA·투명 여백·공통 배율·루트·원본/출력 해시.
- 타입 검사·프로덕션 빌드 통과. 기존 Phaser 청크 크기 경고는 남는다.
- 내장 브라우저 비교 화면: 전체12장 연락판, 전진 재생, 후진4F에서11번 포즈, 왼쪽 반전 확인. 전투 화면 로딩/시작·D 이동·U 피해8(CPU92)·정지 확인. 두 검사 탭 warn/error 없음.
- [비교 화면](evidence/h1-motion-comparison.html)과 [화면 증거](evidence/h1-walk-crossing.png). 화면은 개발 서버에서 제공되며 배포용 빌드에 포함하지 않는다.

## 남은 검수
걷기↔대기 및 즉시 방향 전환의 포즈 연결, 발의 미세한 미끄러짐, 상체/골반 리듬과 다른 공격 보완이 남는다. 자연스러움의 최종 사용자 승인은 아직 없다. 독립 Chrome/Edge·전체 경기/AI는 미검증이며 콤보/잡기/효과음 및 경기 초안의 승인 대기는 유지한다.
